# Типоразмер № 3: согласованная расчётная точка газогенератора

Часть трека «Простая литая ГТУ-заменитель» (`routes/gtu`, issue #59). Решения владельца 14.11.2026:
мягкий допуск пакета (+20 % расхода, +100 °C выхлопа), первым — типоразмер № 3, расчётная точка —
Taurus 60 генераторный (`gtu_family_results.json → slots[Taurus 60, генератор].мягкий`): 1В-2Ц, класс U,
π 13,5, T41 1000 °C, 25,55 кг/с, вал двигателя = вход редуктора пакета 14 950 об/мин.

Задача: `gtu_family` подобрал колесо под собственную частоту (17 640 об/мин, D2 0,51 м, U2 471 м/с), а вал
одновального двигателя обязан вращаться с 14 950 об/мин — при D2 0,51 м это 399 м/с
(`frame3_point_results.json → problem`). Здесь — точка, согласованная при 14 950 об/мин.

## Метод (уровень облика, всё — оценка)

- Ступень компрессора — средняя линия: вход по минимуму относительной скорости на периферии (втулка 0,4),
  скольжение по Wiesner, число лопаток по Пфлейдереру (+ столько же разделительных), угол лопатки на выходе
  30–50° от радиального и cm2/U2 подбираются по наибольшему КПД, U2 не выше 0,9·620 = 558 м/с.
- КПД ступени = принятая формула трека `comp_stage` (она отвечает коэффициенту расхода 0,085) + поправка:
  разность КПД по набору потерь Oh, Yoon, Chung (1997) с трением стенок диффузора между колесом при
  14 950 об/мин и колесом той же ступени при частоте, где коэффициент расхода 0,085. Формулы потерь сверены с
  открытой реализацией TurboFlow 0.1.18 (`centrifugal_compressor/loss_model_oh.py`); статья из среды недоступна.
  Положительная поправка не засчитывается. Правило `gtu_family` (−1,5 п. на ln 1,14 отхода частоты) записано
  для сравнения: здесь отход частоты вне его диапазона 0,84–1,14.
- Распределение π — по наименьшей работе сжатия при U2 ≤ 558 м/с у обоих колёс.
- Турбина — осевая, неохлаждаемая, на среднем диаметре U = 420 м/с (`LIM['U_ax']`), выход без закрутки,
  ca/U = 0,5; КПД ступени `gtu_explore.eta_axial(ψ)`. Годна, если ψ ≤ 2,5, реактивность ≥ 0, число Маха за
  сопловым аппаратом ≤ 1,2.
- Цикл — `gtu_cycle.cycle` с эквивалентным политропным КПД сжатия (та же работа, что у двух ступеней) и одним
  КПД турбины, без переходного канала. Баланс мощности проверен вторым способом: турбина по таблицам
  `gtu_explore`, компрессор и вал по Cantera.
- Исполнения типоразмера — та же геометрия на нерасчётном режиме: средняя линия ступеней, горло соплового
  аппарата по закону конуса Стодолы, граница устойчивости — максимум π на линии частоты, запирание — горла
  входа колеса и диффузора (число Маха 0,8 на расчётном режиме). Точка подтверждается `gtu_cycle.cycle`.

| | ступень 1 (`stage1`) | ступень 2 (`stage2`) |

| D2, м; b2, мм | 0,695; 20,3 | 0,703; 18,6 |

| температура за ступенью | 204 °C | 411 °C |

Поправка КПД почти целиком — трение в узком диффузоре (оценка): без него +0,2 и −0,9 п. вместо −1,2 и −3,2 п.
(`eta_basis.d_eta_without_diffuser_friction`). Без проектного запаса по U2 оптимум — π1 3,94: 5882 кВт и 32,0 %
на валу, но у ступени 2 U2 592 м/с, запас 4,4 % (`split.without_margin`).

Прочность (оценка подобием по примерам `platform/fea`, профили условные): со сквозным отверстием оба колеса
выходят за предел текучести (1,05 и 1,36 σ0,2), без отверстия — 0,58 и 0,75 σ0,2 (`stage*.material`). Значит,
оба колеса — без сквозного отверстия. Ступень 2 работает при 411 °C — на верхней границе данных Ti-6Al-4V
в `materials.json` (до 427 °C); ползучесть титана не оценивалась.

Турбина (`turbine`): одна ступень работу не снимает — нужно 641 кДж/кг газа, одна ступень даёт не больше 441
(ψ 3,39 при пределе 2,5; реактивность −0,70; скорость за соплом больше, чем даёт весь перепад). Две ступени —
ψ 1,79, но за сопловыми аппаратами М 1,24 и 1,44 и мощность 5504 кВт. Годна трёхступенчатая: средний
диаметр 0,537 м, U 420 м/с, ψ 1,21, реактивность 0,39, КПД 0,885, степени расширения 2,02 / 2,29 / 2,75,
высота лопатки 28 мм на входе в первое колесо и 160 мм на выходе последнего. Исходный Taurus 60 GS — тоже
три ступени турбины (`fleet/gtu_fleet_taurus60.json`). У последней ступени AN² 6,0·10⁷ м²·(об/мин)² — нужна
проверка прочности.

Цикл (`cycle`): при 25,55 кг/с и 1000 °C — 5781 кВт на валу и 5535 кВт на клеммах против нужных 5922 и
5670; КПД 31,6 % на валу (30,3 % на клеммах). Модель `gtu_family` на той же точке — 5923 кВт и 31,8 %
(в её результате 29,4 % — после штрафа за частоту). Добрать мощность: расход 26,17 кг/с (допуск 25,69),
или T41 1010 °C, или π около 12 (при тех же КПД узлов 5921 кВт, `pr_sensitivity_fixed_eta`).

для одновальных машин расход не снижает.

## Ограничения

- КПД узлов, пределы окружных скоростей, потери диффузора, горла, граница устойчивости — оценка; числа Маха
  входа у эталонных колёс при φ 0,085 — 1,27 и 1,03, а ударные потери в наборе Oh не учтены.
- Нужны: характеристика ступеней в SU2 (особенно закрытый входной аппарат у запирания), прочность колёс
  без отверстия и последней ступени турбины в CalculiX, данные Ti-6Al-4V выше 400 °C, эксперимент.
- Каталог данных (`tools/build_catalog.mjs`) определяет трек по префиксу `gtu_`; имена файлов этой папки
  префикса не имеют.
