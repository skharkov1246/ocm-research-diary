# Типоразмер № 3: согласованная расчётная точка газогенератора

Часть трека «Простая литая ГТУ-заменитель» (`routes/gtu`, issue #59). Решения владельца 14.11.2026:
мягкий допуск пакета (+20 % расхода, +100 °C выхлопа), первым — типоразмер № 3, расчётная точка —
Taurus 60 генераторный (`gtu_family_results.json → slots[Taurus 60, генератор].мягкий`): 1В-2Ц, класс U,
π 13,5, T41 1000 °C, 25,55 кг/с, вал двигателя = вход редуктора пакета 14 950 об/мин.

Задача: `gtu_family` подобрал колесо под собственную частоту (17 640 об/мин, D2 0,51 м, U2 471 м/с), а вал
одновального двигателя обязан вращаться с 14 950 об/мин — при D2 0,51 м это 399 м/с
(`frame3_point_results.json → problem`). Здесь — точка, согласованная при 14 950 об/мин.


`../gtu_family.py` (`SCEN`, `COOL`, `ETA_GEN`), `../gtu_cycle.py`, `../platform/fea/materials.json`,
`../platform/fea/disk_results.json`.

## Метод (уровень облика, всё — оценка)

- Ступень компрессора — средняя линия: вход по минимуму относительной скорости на периферии (втулка 0,4),
  скольжение по Wiesner, число лопаток по Пфлейдереру (+ столько же разделительных), угол лопатки на выходе
  30–50° от радиального и cm2/U2 подбираются по наибольшему КПД, U2 не выше 0,9·620 = 558 м/с.
- КПД ступени = принятая формула трека `comp_stage` (она отвечает коэффициенту расхода 0,085) + поправка:
  разность КПД по набору потерь Oh, Yoon, Chung (1997) с трением стенок диффузора между колесом при
  14 950 об/мин и колесом той же ступени при частоте, где коэффициент расхода 0,085. Формулы потерь сверены с
  открытой реализацией TurboFlow 0.1.18 (`centrifugal_compressor/loss_model_oh.py`); статья из среды недоступна.
  Положительная поправка не засчитывается. Правило `gtu_family` (−1,5 п. на ln 1,14 отхода частоты) записано
  для сравнения: здесь отход частоты вне его диапазона 0,84–1,14.
- Распределение π — по наименьшей работе сжатия при U2 ≤ 558 м/с у обоих колёс.
- Турбина — осевая, неохлаждаемая, на среднем диаметре U = 420 м/с (`LIM['U_ax']`), выход без закрутки,
  ca/U = 0,5; КПД ступени `gtu_explore.eta_axial(ψ)`. Годна, если ψ ≤ 2,5, реактивность ≥ 0, число Маха за
  сопловым аппаратом ≤ 1,2.
- Цикл — `gtu_cycle.cycle` с эквивалентным политропным КПД сжатия (та же работа, что у двух ступеней) и одним
  КПД турбины, без переходного канала. Баланс мощности проверен вторым способом: турбина по таблицам
  `gtu_explore`, компрессор и вал по Cantera.
- Исполнения типоразмера — та же геометрия на нерасчётном режиме: средняя линия ступеней, горло соплового
  аппарата по закону конуса Стодолы, граница устойчивости — максимум π на линии частоты, запирание — горла
  входа колеса и диффузора (число Маха 0,8 на расчётном режиме). Точка подтверждается `gtu_cycle.cycle`.

Поправка КПД почти целиком — трение в узком диффузоре (оценка): без него +0,2 и −0,9 п. вместо −1,2 и −3,2 п.
(`eta_basis.d_eta_without_diffuser_friction`). Без проектного запаса по U2 оптимум — π1 3,94: 5882 кВт и 32,0 %
на валу, но у ступени 2 U2 592 м/с, запас 4,4 % (`split.without_margin`).

Прочность (оценка подобием по примерам `platform/fea`, профили условные): со сквозным отверстием оба колеса
выходят за предел текучести (1,05 и 1,36 σ0,2), без отверстия — 0,58 и 0,75 σ0,2 (`stage*.material`). Значит,
оба колеса — без сквозного отверстия. Ступень 2 работает при 411 °C — на верхней границе данных Ti-6Al-4V
в `materials.json` (до 427 °C); ползучесть титана не оценивалась.

Турбина (`turbine`): одна ступень работу не снимает — нужно 641 кДж/кг газа, одна ступень даёт не больше 441
(ψ 3,63 при пределе 2,5). Если считать одноступенчатый вариант согласованно, с его КПД 0,81, мощность падает до
4709 кВт, нужно 598 кДж/кг, и всё равно ψ 3,39, реактивность −0,70, скорость за соплом больше, чем даёт весь
перепад (`turbine.options.1`). Две ступени —
ψ 1,79, но за сопловыми аппаратами М 1,24 и 1,44 и мощность 5504 кВт. Годна трёхступенчатая: средний
диаметр 0,537 м, U 420 м/с, ψ 1,21, реактивность 0,39, КПД 0,885, степени расширения 2,02 / 2,29 / 2,75,
высота лопатки 28 мм на входе в первое колесо и 160 мм на выходе последнего. Исходный Taurus 60 GS — тоже
три ступени турбины (`fleet/gtu_fleet_taurus60.json`). У последней ступени AN² 6,0·10⁷ м²·(об/мин)² — нужна
проверка прочности.

Цикл (`cycle`): при 25,55 кг/с и 1000 °C — 5781 кВт на валу и 5535 кВт на клеммах против нужных 5922 и
5670; КПД 31,6 % на валу (30,3 % на клеммах). Модель `gtu_family` на той же точке — 5923 кВт и 31,8 %
(в её результате 29,4 % — после штрафа за частоту). Добрать мощность: расход 26,17 кг/с (допуск 25,69),
или T41 1010 °C, или π около 12 (при тех же КПД узлов 5921 кВт, `pr_sensitivity_fixed_eta`). T41 1010 °C —
по `gtu_cycle.cycle`; нерасчётная модель (таблицы `gtu_explore`, `members`) даёт 1013 °C: на расчётной точке
она показывает 5772 кВт против 5781 (`offdesign_selfcheck`, 0,15 %).

## Ограничения

- КПД узлов, пределы окружных скоростей, потери диффузора, горла, граница устойчивости — оценка; числа Маха
  входа у эталонных колёс при φ 0,085 — 1,27 и 1,03, а ударные потери в наборе Oh не учтены.
- Нужны: характеристика ступеней в SU2 (особенно закрытый входной аппарат у запирания), прочность колёс
  без отверстия и последней ступени турбины в CalculiX, данные Ti-6Al-4V выше 400 °C, эксперимент.
- Каталог данных (`tools/build_catalog.mjs`) определяет трек по префиксу `gtu_`; имена файлов этой папки
  префикса не имеют.

Найдено независимой проверкой 14.11.2026 (повтор расчёта в чистой копии дал тот же JSON байт в байт;
числа ниже — прогоны проверяющего, в `frame3_point_results.json` не входят, оценка):

- Распределение π выбрано не по минимуму работы. Угол лопатки перебирается шагом 5°, а предел U2 558 м/с
  активен, поэтому работа сжатия от π1 идёт «пилой», и ограниченный поиск Брента останавливается не в
  минимуме. На сетке π1 с шагом 0,02 у той же модели минимум — π1 4,70: 406,7 кДж/кг против 408,2 при
  π1 4,49 (−0,35 %); мощность на валу 5819 кВт против 5781 (98,3 % нужной), D2 0,708 и 0,712 м, U2 554 и
  557 м/с.
- В `best()` после округления числа лопаток U2 повторно с пределом не сверяется: при π1 4,50 у ступени 2
  выходит 559,0 м/с при пределе 558. Выбранная точка (544 и 550 м/с) предел не нарушает.
- У двустороннего колеса ступени 1 трение стенок диффузора посчитано по ширине одной половины b2, хотя трение
  диска обнулено как у общего колеса. Если диффузор общий шириной 2·b2, то η_p1 = 0,851 вместо 0,844, а
  мощность 5860 кВт (98,9 %). Значит, недобор 2,4 % мощности при 1000 °C лежит в пределах чувствительности
  самой модели. Устойчивые выводы — число ступеней турбины и облик колёс.
- Колёса турбины по наружному диаметру — 0,574, 0,608 и 0,697 м — больше предела цельной отливки осевого колеса
  0,50 м (`gtu_explore.LIM['D_axcast']`, README трека). Нужна конструкция «диск + лопатки». Колёса компрессора
  (0,695 и 0,703 м) укладываются в предел титановой поковки 0,90 м (`LIM['D_ti_max']`), но как цельные
  отливки были бы на пределе 0,70 м для радиального колеса и выше него.
- Скорость за последней ступенью турбины 210 м/с (число Маха около 0,4), её кинетическая энергия — около
  22 кДж/кг, или 3,4 % работы турбины. Цикл расширяет газ по полному давлению до 1,02 атм, то есть считает эту
  энергию восстановленной в выхлопном диффузоре.
- `gtu_cycle.poly_process` делает 40 шагов. При тех же КПД ступеней работа сжатия занижена на 0,13 %
  (407,6 против 408,2 кДж/кг), отсюда 9 кВт разницы между `cycle.frame3` и `offdesign_selfcheck`.
- У Centaur 40 и 50 запас до запирания (0,4 и 1,1 %) меньше точности одномерной модели: горло посчитано при
  принятом числе Маха 0,8, потери у запирания и потери в самом входном аппарате в модели не учтены. Поэтому
  вывод «да, с входным аппаратом» пока не установлен.

## Геометрия и сетки колёс компрессора (`frame3_geom.py`)

| Файл | Что это |
|---|---|
| `frame3_geom.py` | STEP колёс ступеней 1 и 2 и сетки одного межлопаточного канала SU2 по точке; независимая проверка файлов |
| `frame3_geom_results.json` | итог: размеры, качество сеток, проверки, пути и SHA-256 больших файлов; `method`, `software`, `date`, `inputs` |
| `test_frame3_geom.py` | перенос чисел точки в узел (без Gmsh) и проверка итогового JSON, секунды |

```bash
python3 frame3_geom.py --out <папка вне репозитория> --levels coarse medium   # около 10 мин на 4 ядрах
python3 -m pytest -q test_frame3_geom.py
```

Узел — `../platform/geom/impeller.py` (Gmsh 4.15.2 / Open CASCADE). Для точки в нём добавлено (обратно
совместимо, по умолчанию всё как раньше): полные параметры на входе `T01`, `p01`; заданные `D1s`, `b2`, `Lz`,
`beta1h`, `beta1s`; двусторонний вход `double_sided` — `m` остаётся расходом колеса, одна сторона (1D-увязка,
канал, сетка) строится на `m/2`, STEP — обе стороны зеркально на общем диске. Тест узла — `TestDoubleSided`
(SYNTHETIC-колесо), две проверки без Gmsh и новые отказы на недопустимых данных.

Числа из точки (`stage1`, `stage2`): D2, D1 втулки и периферии, b2, осевая длина, углы лопатки на входе
(углы потока точки) и на выходе (50° и 40° от радиального), 9 + 9 лопаток, зазор, 14 950 об/мин, T01 и p01.
Принято здесь: колёса без сквозного отверстия (`stage*.material`), полулопатка с доли 0,30 длины (вес
разделительной лопатки точки 0,7), лопатки двух сторон напротив друг друга, общий диск ступени 1 у r2
толщиной 20,8 мм (0,03 D2). Толщины лопаток, контуры Безье, закон углов — значения узла по умолчанию.

| | ступень 1 (одна сторона из двух) | ступень 2 |
|---|---|---|
| D2 / b2, мм | 694,6 / 20,34 | 702,5 / 18,63 |
| D1 втулки / периферии, мм; осевая длина, мм | 134,3 / 335,9; 195,9 | 116,4 / 290,9; 211,0 |
| лопатки; угол охвата | 9 + 9; 100,7° | 9 + 9; 103,2° |
| объём STEP, дм³ (масса из Ti-6Al-4V, кг) | 39,39 (174,5, обе стороны) | 23,94 (106,0) |

Сетка — тетраэдры, маркеры `inlet outlet hub shroud blade periodic_1 periodic_2`, `periodic_2` = поворот
`periodic_1` на +40° вокруг +z, ω = 1565,6 рад/с (`stages.*.su2`). Проверки по самим файлам
(`checks`, локально): SU2 разобран numpy — только тетраэдры, объёмы > 0, граница замкнута и размечена полностью,
узлы `periodic_1` после поворота совпадают с `periodic_2` (до 2·10⁻¹⁶ м), D2, b2, D1 и зазор по узлам
маркеров равны заданным; STEP прочитан обратно — одно тело, объём по частям, getMass OCC и объём
тетраэдрической сетки STEP сходятся (до 1,1·10⁻⁴), у ступени 1 узлы рёбер зеркальны относительно средней
плоскости диска. Масса завышена: облегчений диска нет.

Большие файлы (STEP, `.su2`; medium хранится сжатым `.su2.gz`) — вне репозитория, в JSON — путь и SHA-256.
Не сделано: SU2 эти сетки не читал; пристенных призм нет; маркер `hub` включает неподвижную стенку
безлопаточного участка за колесом — у ступени 1 сетка одной стороны отвечает диффузору из «двух половин»;
для общего диффузора 2·b2 с тонкой кромкой диска эту стенку надо задать плоскостью симметрии, а для этого
маркер разделить. В точке nu = 0,4 принят под вал через оба колеса, а прочность требует колёс без отверстия —
крепление колёс не прорабатывалось. При пересчёте точки по замечаниям проверяющего (π1 около 4,70)
геометрию надо перестроить (`test_frame3_geom.py` сверяет SHA-256 точки).
