# evo/core — общий модуль эволюционной геометрии (представления формы и поиск)

Часть трека «Простая литая ГТУ-заменитель» (`routes/gtu`, issue #59), задача владельца 15.11.2026: «неординарные и
эволюционные варианты геометрии — не только самые эффективные, но и эффектные». Модуль создан семейством «корпус-оболочка
и рама» (`../shell/`) и общий для всех семейств `routes/gtu/evo/*`. Семейство лопаток (`../blades/`) начало раньше, чем
модуль был готов, и пользуется своим `core_local.py` — так задумано, чтобы не было конфликта правок.

Статус: **черновик, локально проходит 10 проверок** (`python3 test_core.py`, ~6 с); ничего не закоммичено.

## Урок, на котором стоит модуль

Воксельные «живые» топологии проверку в CalculiX на гладкой геометрии не прошли (`../../organic/structure/README.md`, п. 2):
пики у вершин полостей и уступов, которые воксели «затупляют». Поэтому здесь — **только гладкие представления**: неявные
поверхности со скруглениями, B-сплайны, FFD, решётки с плавной плотностью, ветвящиеся каналы с гладкими ветвями.
Вокселизация есть только как **проверка** (стенка, нависания, порошок), а не как способ задать форму.

## Модули

| Файл | Что это |
|---|---|
| `islands.py` | сид острова `sha256(seed │ номер │ соль)`; остров i — в части `i mod n_parts` (разбиение ровно одно); прогон части в процессах (итог не зависит от их числа); слияние архивов: недостающие, лишние, повторные острова, чужая конфигурация (хэш), отчёт `complete` / «НЕПОЛНОЕ: нет N островов» |
| `archive.py` | MAP-Elites: сетка дескрипторов с явными границами бинов, архив (при равном фитнесе — меньший uid: итог не зависит от порядка), операторы: гаусс, iso+line, SBX, полиномиальная мутация; цикл `map_elites` с начальными родителями (выбор владельца) |
| `nsga2.py` | NSGA-II с правилами допустимости Деба, скученность, гиперобъём 2D и Монте-Карло, ZDT1, IGD |
| `cmaes.py` | CMA-ES (ask/tell) в границах [0, 1] со штрафом за выход; итог никогда не хуже начальной точки |
| `shapes.py` | B-сплайны (открытые и периодические), кривизна, полный поворот, самопересечения; SDF: примитивы, тело вращения по 2D-контуру, гладкие объединение/вычитание (скругление k), оболочка; TPMS (гироид, Шварц P, алмаз) с переменной толщиной листа и таблица плотности; решётка Вороного (открытая/закрытая); FFD с обратным отображением и якобианом; дерево Мюррея с гладкими ветвями; L-система и черепаха; поле расстояний до отрезков на развёртке; C²-профиль ребра |
| `checks.py` | вокселизация SDF; наименьшая стенка (EDT, гребень, поправка ±h/2); нависания (доля площади, обращённой вниз круче 45°); вынос порошка (замкнутые полости, недоступный шару диаметра d объём); гладкость контура |
| `mesh.py` | surface nets по SDF (без scikit-image), оболочка вращения с рельефом r(z, θ), трубки, объём и площадь, STL |
| `blade.py` | сплайновая лопатка: законы хорды, закрутки, толщины, стреловидности, навала и изгиба; бугорки передней кромки, серрации задней кромки, риблеты |
| `features.py` | признаки «эффектности»: новизна (k ближайших; расстояние до типовых форм OEM), гладкость (скачок кривизны, энергия изгиба, перегибы), коробочная размерность, дефицит выпуклости, порядок вращательной симметрии и зеркальность |
| `render.py` | лист из трёх видов в одном масштабе (сбоку, с торца, аксонометрия 55°/30°), монохром, Liberation Serif, подпись «эскиз формы (оценка), не является конструкторской документацией»; миниатюры и галерея; pyvista (OSMesa) или matplotlib |
| `sources.py` | источники методов и биомиметических приёмов со статусом («по памяти», «гипотеза», свой расчёт с файлом) |
| `test_core.py` | 10 проверок (ниже) |

## Как пользоваться (семейство)

```python
from core import archive as A, islands as IS
grid = A.GridSpec(names, edges)                      # дескрипторы — геометрические признаки «разности вида»
def run_island(i, **kw):                              # остров: свой сид, свой архив
    ar = A.Archive(grid); rng = IS.rng_for(seed, i, salt=variant)
    A.map_elites(evaluate, dim, ar, rng, n_evals, init=parents)
    return dict(island=i, config_hash=h, evals=n_evals, archive=ar.to_dict())
res = IS.run_part(run_island, n_islands, n_parts, part, workers=NPROC)
merged, report = IS.merge_archives(all_islands, range(n_islands), h)   # неполное — ошибка
```

Геном — всегда вектор в [0, 1]^d; перевод в форму (`decode`) — дело семейства.
