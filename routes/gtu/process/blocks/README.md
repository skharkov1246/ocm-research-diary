# Библиотека блоков процесса «от топлива до вала»

Узел трека «Простая литая ГТУ-заменитель» (`routes/gtu`, issue #59), папка `process/blocks`. Фокус владельца 15.11.2026:
«подбираем топовые конструкции всего процесса — от поступления топлива до вала; глубже в расчёты не погружаемся; концентрируемся
на геометрии, которая даст наибольшую эффективность и значительно повысит КПД на тонну агрегата». Здесь — кирпичи для такого
подбора: шесть блоков с вариантами и быстрыми моделями, правила совместимости и один вызов `evaluate(concept)`.

**Статус — черновик, уровень облика (0D-цикл + одномерные размеры). Всё — оценка**: КПД узлов, потери, пределы, счёт деталей и
TRL — принятые величины трека и собственные оценки, перечисленные ниже. Внешние факты — с пометкой «открыт» или «по выдержке
поиска» в исходных модулях. Числа этого README — из `blocks_results.json` (поля в скобках).

## Как вызвать

```python
import sys; sys.path.insert(0, "routes/gtu/process")
import blocks
r = blocks.evaluate(dict(
    kv="KV-3",                                                     # стык пакета: KV-3 (Taurus 60 GS), KV-1, KV-6
    fuel=dict(prep="нет"),                                         # нет | подогрев | паровой риформинг | сухой риформинг
    compressor=dict(arch="2Ц", pi=8.2, intercool="нет"),           # 1Ц | 2Ц | Д | ОЦ (+ n_ax); промохлаждение «воздух»
    combustor=dict(scheme="LPP"),                                  # LPP | FLOX | TVC | CAT | RDC | ВР
    turbine=dict(type="О", cool="U", mat="SC", t41=1000),          # О | Р; U | N | K | P | C
    hx=dict(recup=0.90, recup_make="фольга", reheat=True, x_rh=0.35, ibc=False),
    shaft=dict(drive="прямой"),                                    # прямой | свободная СТ | быстроходный
))
r["eff_shaft"], r["eff_el"], r["G_air"], r["W_exh"], r["EGT_C"], r["interface"], r["feasible"], r["reject"]
r["parts"], r["trl"], r["plugplay"], r["sizing"], r["blocks"]      # детали, готовность, Plug&Play, размеры для модели массы
```

Пропущенное берётся из `concept.DEFAULT`. Вызов — 1–50 мс (быстроходный вал — около 0,1 с: перебор частоты), первый — около
1 с (импорт). Самопроверка: `python3 blocks_selfcheck.py` (6–9 с) → `blocks_results.json`; тесты:
`python3 -m pytest -q test_blocks.py` (19 проверок, около 7 с). AWS не вызывается.

## Что внутри `evaluate`

1. Совместимость по описанию (`compat.check_static`).
2. Воронка: концепция переводится в концепцию воронки (`concept.to_funnel`), `funnel_l0.solve` даёт КПД ступеней компрессора
   и турбин по геометрии (быстрый цикл `funnel_space.quick_perf`, геометрия `derive`, поправки `funnel_l0.corrections`),
   число ступеней «auto»; у быстроходного вала — перебор частоты в окне отношения частот.
3. Цепочка блоков (`chain.run`) с этими КПД — таблицы свойств gtu_explore, логика `funnel_space._core` плюс промохлаждение,
   рекуператор, подогрев, рост давления, подогрев топлива, IBC. Химическая рекуперация — приращение из перебора циклов.
4. Геометрия при расходе и температурах цепочки (`funnel_space.derive`), правила воронки (`check`), детали / обслуживание /
   Plug&Play / изготовимость (модели воронки), добавочные узлы теплообмена (`cycles.parts`), сердцевины (`cycles.size_hx`),
   готовность — наименьший TRL и множитель владельца (0,5 + 0,5·TRL/9).
5. Допуск пакета: воздух и выхлоп до +20 %, выхлоп до +100 °C (решение владельца 14.11.2026). Выход `interface` показывает
   также мощность при предельном расходе (`P_at_G_cap_kW`).

Модели трека только вызываются; единственное вмешательство — регистрация точки с другой частотой вала в кэше
`funnel_space._TGT` под ключом `PB:...` (для быстроходного варианта; файлы не меняются).

## Совместимость (что с чем нельзя и почему; `compat.TABLE`)

Жёсткие (концепция недопустима):
- промохлаждение — только при двух и более ступенях сжатия (1Ц и Д — нет);
- подогрев на одном валу — осевая турбина не меньше двух ступеней (между радиальными колёсами камере нет места, оценка);
- класс C — керамическое радиальное колесо Si3N4; класс P — печатная горячая часть; монокристалл — осевая турбина;
  никелевое колесо компрессора — только заодно или сваркой с турбиной;
- быстроходный вал и одновальный прямой привод — только генераторные пакеты; кластер ядер — на общую свободную СТ;
- каталитическая камера при воздухе холоднее 723 K — предгорелка со своим клапаном против «один клапан на топливо»;
- камеры предварительного смешения — газ за камерой не горячее 1850 K (зона пламени, NOx 9 ppm, `targets.json`);
- газ на входе рекуператора ≤ 700 °C; оболочка — в камере LPBF; пределы воронки (окружные скорости, размеры, AN², φ).

Мягкие (предупреждение, вторичная цель): паровой риформинг — вода, Plug&Play «нет»; сухой риформинг — кислород выхлопа сжигает
метан, сажа выгодна; рост давления с рекуператором или классом U — вне шаблонов воронки; IBC за рекуператором ε ≥ 0,85;
подогрев — второй клапан; вынесенные охладители — рама и укрытие. Выбросы (`nox_gas`, `co_gas`) показываются, но не отсеивают:
ни один из 262 144 вариантов уровня 0 камеры не выполняет все жёсткие цели (`hard_ok` 0).

## Размеры для модели массы (`sizing`)

Двигатель — диаметры колёс, корпуса, горячей части, камеры, турбин и силовой турбины, длины, габарит (`funnel_space.derive`,
`funnel_l0.envelope`), материалы и плотности; сердцевины теплообменников — объём, площадь, масса, модули (`cycles.size_hx`,
технология концепции). Массы модулей воронки приведены как вход, **не как итог**: на опорной точке KV-3 формула воронки даёт
1463 кг против 3290 кг паспортной массы двигателя Taurus 60 (`mass_reference`, отношение 2,25) — модель массы должна
калиброваться по машинам.

## Допущения и пределы

- КПД ступеней — по базовому ядру концепции; промохлаждение, подогрев и IBC не пересчитывают нагрузку ступеней.
- Подогрев: повторная ступень охлаждается тем же классом; деление топлива между камерами не моделируется.
- Риформинг — суперпозиция приращения перебора циклов; IBC — без конденсации воды (сверка с перебором — до 0,05 п. п.).
- Волновой ротор — та же модель эквивалентного давления, что у RDC (своей нет).
- Порог воздуха на входе смесителя LPP и TVC 650 °C — оценка (прецедент Mercury 50 — рекуператор и бедная камера; температура
  на входе его камеры не опубликована).
- Окно частоты быстроходного вала 0,70–1,60 и TRL 7 сменной пары — оценка, проверить у изготовителя редуктора.
- Точки пакета — KV-1, KV-3, KV-6 (`funnel_space.KV`); другие исполнения — после добавления точки в воронку.
