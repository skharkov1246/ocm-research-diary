# Камера сгорания KV — воронка, уровень 0

Узел трека `gas-turbine` (двигатель-заменитель KV, issue #59). Задача владельца 14.11.2026: переработать горение,
форсунки и каналы перебором на AWS так, чтобы камера была проще и лучше существующих. Приоритеты: минимум деталей
(главное), Plug&Play в пакет Solar/Siemens (один регулирующий клапан на топливо), монтаж и ремонт «хоть уборщиком»
(сменный картридж), затем КПД и размер. Цели камеры — `targets.json` (обоснование — `targets_basis.py`,
`STATE_OF_ART.md`).

Состояние на 14.11.2026: код уровня 0, тесты (23 passed) и локальная отладка готовы. Модель прошла проверку скептика
(раздел «Проверка скептика» ниже): убраны выгоды, которые схемы получали даром, отладка перезапущена в чистой копии.
Пакет задач для AWS проверен командой `plan` раннера (без AWS). Живого запуска не было: его делает отдельная сессия
с ключами. Ничего не коммитилось.
Все числа ниже — уровень облика (0D-сети реакторов + корреляции), то есть **оценка** для отбора на L1 (RANS).
Это не прогноз выбросов конструкции.

## Пространство поиска (`comb_space.py`)

Дискретные оси (у каждой схемы свой список допустимых значений, `SCHEMES`):
- **схема:**
  - бедное предварительное смешение (LPP);
  - микросмешение (MM);
  - MILD/FLOX;
  - RQL;
  - захваченный вихрь (TVC);
  - каталитическая (CAT, со штрафом готовности TRL 6);
  - детонационная (RDC, со штрафом готовности TRL 4).
  Все TRL — оценка по `STATE_OF_ART.md`, разд. 4.
- **камера:** одна выносная / 6 трубчатых / кольцевая встроенная / противоточная;
- **форсунка:** закрутка / струи в сносящем потоке / микросмесители;
- **подача дизеля:** центробежная / пневматическая (LDI) / испарительная;
- **охлаждение стенки:** плёночное / многодырчатая эффузия / печатная решётка (последовательно, перепад `dp_wall`) / вкладыш CMC;
- **изготовление:** печатный картридж / литьё / гибрид;
- **пассивное деление топлива** (добавлено к заданию: по `targets_basis` один клапан держит пламя только на 83–100 %):
  - нет;
  - гидравлика: пилот через отверстие (расход ~ ΔP^0,5), основной контур через ламинарные капилляры (~ ΔP);
  - самостратификация струй: расслоение у входа канала затухает по длине смешения тем же законом exp(−l/2,5), что и
    неравномерность (проверка скептика: без затухания канал давал почти идеальное смешение на 100 % и полное
    расслоение на 30 % одновременно).

Непрерывные оси:
- число элементов и струй на элемент, диаметр топливной струи;
- крутка;
- доля воздуха в зоне горения и вспомогательная доля (пилот, полость, гашение);
- сила пассивного деления;
- времена пребывания: в зоне пламени, догорания, разбавления;
- L/D жаровой трубы; длина и диаметр трубы получаются из объёма зон;
- перепад на смесителе и на решётке стенки;
- пористость охлаждения;
- длина смешения.

Диаметр струи сэмплируется внутри окна, где давление топливного газа равно 1,03–2,5·p3 (оценка: давление топлива
в пакетах не опубликовано). Так выборка не тратится на заведомо негодные отверстия.

## Модель уровня 0 (`comb_crn.py`)

Вход — расчётная точка KV-3 (`frame3_point_results.json`, мягкий допуск):
- p3 = 1367,9 кПа, T3 = 683,5 K, воздух 25,17 кг/с, метан 0,3653 кг/с — совпадает с `targets_basis` до 6 знаков;
- 50 % нагрузки — T41 = 779,0 °C; 30 % — T41 = 683,6 °C. Допущения частичной нагрузки — как в `targets_basis`
  (постоянные частота и расход воздуха; оценка).

| часть | как считается | статус |
|---|---|---|
| смешение | неравномерность S = 0,01 + 0,5·f_C·exp(−l/2,5)·(1 − 0,3·(крутка − 0,4)+); f_C — отклонение C = (S/H)·J^0,5 от оптимума 2,5 (Holdeman, PECS 1993); в квадратуре — разброс раздачи 2σd/d по отверстиям (k_je на элемент) и каналам: σd печать 0,025 мм, сверление 0,008, литой канал 0,05 | константы и σd — оценка; форма Holdeman — по памяти, не сверено |
| зона пламени | PSR GRI-Mech 3.0, 5 узлов Гаусса — Эрмита по φ у всех схем (RQL — 1); рециркуляция продуктов догорания в корень пламени (закрутка K = 0,5·(S − 0,4)+; FLOX — унос по Ricou — Spalding 0,32·x/d·(ρ/ρ0)^0,5 до длины, на которой струя заполняет свою ячейку сечения, (D_ячейки − d0)/(2·0,22), не дальше 0,5·L_трубы, не больше 3) | форма Ricou — Spalding — по выдержке поиска; рост струи 0,22 — по памяти; остальное — оценка |
| догорание и разбавление | узлы раздельно идут 30 % времени догорания, затем вместе (бедные струйки дожигаются), затем воздух разбавления и PFR | оценка |
| RQL | богатая PSR → гашение тремя PSR (воздух тремя долями) → бедная PFR | оценка |
| TVC и гидравлический пилот | PSR полости (пилота) → её горячий газ входит в узлы основной зоны | оценка |
| CAT | бедная предгорелка до 723 K → превращение на катализаторе до 1173 K → гомогенное догорание PFR (задержка — расчётом) | пороги — оценка |
| RDC | сгорание при постоянном объёме (UV) вместо волны, NOx за τ_pz, расширение, PFR; прирост давления не засчитывается (ETA_PG = 0; было 0,05·(p_cv/p3 − 1) ≈ 10 % p3), p_cv/p3 — в результате; предел детонации φ ≥ 0,6 | грубая оценка |
| срыв | запас = τ / τ_погасания, бисекция PSR | расчёт |
| проскок | g_стенки(u_min) / (25·S_L²/α); u_min — вихревое ядро закрутки или след струи; K = 25 подобран так, что опорный серийный завихритель держит метан (запас 2,4) и 50 % H2 (1,6), но не 100 % H2 (0,33) | подбор — оценка; числа Льюиса не учтены |
| самовоспламенение | задержка (таблица) / время в смесителе; запас не меньше 3 и для газа (H2), и для испарительной подачи дизеля | расчёт; запас 3 — оценка |
| дизель | н-додекан, механизм Reitz (Fuel 136, 2014): равновесие → перенос на GRI → NOx в PFR; SMD — Lefebvre (центробежная) и El-Shanawany — Lefebvre (предплёночная); испарение по закону d²; доля диффузионного горения t_mix/(t_mix + t_chem) | формы — по памяти, не сверено; быстрый NOx не учтён (оценка снизу) |
| стенка | одномерный баланс в форме Lefebvre & Ballal (излучение газа 1 − exp(−290·P·L·(q·l_b)^0,5·T^−1,5), конвекция 0,020·k/D^0,2·(ṁ/Aμ)^0,8, плёнка — щелевая формула 1,10·m^0,65·(…) при m ≤ 1,3, выше 1,28·(…)); ε_стенки 0,7 | константа 290, l_b = 3,4·V/A и ε = 0,7 — по выдержке поиска; остальное по памяти |
| PF | θ·[1 − exp(−1/(A·L/D·ΔP_L/q_ref))] (A = 0,070 трубчатые, 0,050 кольцевые) ⊕ унаследованная неравномерность; θ — перенос с обычных камер на бедные | форма — по памяти, не сверено |
| потери давления | диффузор (M3 = 0,2, K по типу камеры) + смеситель + трение смесительного канала f·l_mix·Cd²·dp_inj (Haaland; шероховатость печать 0,03 мм, литьё 0,005 мм) + решётка + горячие (Рэлей) + переходный канал; цена — 49,4 кВт и 0,27 п.п. КПД на процент (`targets_basis`) | оценка + расчёт |
| модуль | правила подсчёта деталей, сварок, центровок (кожух с фланцем у выносной и трубчатых — как в составе цели parts_count; переходный патрубок выносной, как и в составе цели, не считается, у трубчатых патрубки считаются); время замены по типу камеры; Plug&Play (клапаны, давление топлива, смена топлива, стык); изготовимость по форме `make_model` воронки двигателя (принтеры — по выдержке поиска) | оценка |
| цели | все 13 целей `targets.json` с величиной, пределом и нарушением; жёсткие — по `funnel_interface.hard`; если зона погасла на 100 или 50 % (полнота < 0,99), цели NOx и CO не выполнены | — |

Сайты с первоисточниками корреляций из этой среды не открылись (`apps.dtic.mil`, `www.conference.isabe.org` —
нет в разрешённых адресах). Формы Lefebvre, Holdeman и El-Shanawany записаны по памяти и помечены «не сверено».

## Стык с воронкой двигателя

`merge_l0.py` пишет в `feed_to_engine_funnel.best` лучший вариант каждой пары «схема × тип камеры». Поля
(`targets.json → funnel_interface`):
- `dp_comb`, `D_comb`, `L_comb`, `m_comb`, `n_inj`;
- `parts`;
- NOx и CO на 100 / 50 / 30 %;
- `PF`, `RTDF`, `T_metal_max_K`;
- `fuel_valves`, `H2_vol_max`;
- NOx дизеля на 100 / 50 %;
- `cartridge_swap_h`, `V_L`;
- `burnt` — горит ли зона на 100 / 50 / 30 % (False — NOx и CO этой точки не годятся).

Они заменяют заглушки `funnel_space.py`: потери 4 / 5 %, D_comb = 1,1·Dc, L_comb = 0,6·D_comb, масса трубы по 2 мм,
число форсунок. Файлы воронки двигателя здесь не правились.

research-collection.ethz.ch, collections.lib.utah.edu — нет в разрешённых адресах; сверка по выдержкам поиска и
независимым расчётом Cantera напрямую, без классов `comb_crn`):
- **NOx идеального премикса.** PSR 1 мс + PFR 10 мс, GRI-Mech 3.0, 13,7 бар, T3 683,5 K, против подгонки Leonard &
  Stegmaier по почти идеальному премиксу NOx = 2,635·10^7·exp(−28695/T_ad) ppm при 15 % O2 (по выдержке поиска; показатель
  восстановлен из OCR, не сверено): T_ad 1673 / 1764 / 1852 / 1936 / 2018 K — расчёт 0,80 / 2,34 / 6,38 / 18,0 / 50,4 ppm,
  подгонка 0,93 / 2,26 / 4,90 / 9,66 / 17,6 ppm (отношение 0,86 / 1,04 / 1,30 / 1,86 / 2,86). В рабочем окне вариантов
  (1700–1850 K) расхождение не больше 30 %; выше 1900 K расчёт растёт со временем пребывания, а подгонка заявлена не
  зависящей от него (2–100 мс, по выдержке поиска). Давление: при φ 0,55 — 7,1 / 6,4 / 7,1 ppm на 1 / 13,7 / 30 бар,
  как и у Leonard & Stegmaier (нет заметной зависимости). Что GRI-Mech 3.0 с простыми реакторами хорошо описывает
  NOx и CO опытов в реакторах высокого давления (Rutar & Malte, J. Eng. Gas Turbines Power 124, 2002) — по выдержке
  поиска; числа опытов недоступны.
- **Погасание PSR** (независимая бисекция, старт с равновесия): τ_погасания 4,40 / 1,56 / 0,61 / 0,27 / 0,13 / 0,071 мс
  при φ 0,35 … 0,60 (T_ad 1481 … 1936 K). Срыв около T_ad 1500–1600 K при 1–4 мс — в полосе, обычной для бедного
  премикса (по памяти, не сверено). Запас idx 233 на 100 % без рециркуляции: независимо 3,96, в модели 4,53 (модель
  продолжает горящее решение — τ_погасания чуть меньше).
- **Задержки самовоспламенения.** Метан (GRI) при 655 K и 13,7 бар не воспламеняется за 100 мс — модель берёт 100 мс
  (консервативно). Н-додекан (Reitz): 12,7 мс при 683 K, 13,7 бар, φ 0,6; при 20 атм — 1,7 мс (800 K, φ 1),
  4,5 / 2,9 / 1,5 мс (800 / 900 / 1000 K, φ 0,5). По памяти (не сверено) опыты ударной трубы при 20 атм дают в 2–3 раза
  меньше, поэтому запас по самовоспламенению испарительной подачи поднят до 3, как у газа.
- **Корреляции стенки и неравномерности** сверены с формами Lefebvre & Ballal (по памяти): излучение, конвекция внутри
  и снаружи, Z внешнего излучения, L = 336/H², PF = 1 − exp(−1/(A·L/D·ΔP_L/q_ref)) — совпадают. Ошибка: щелевая плёнка
  1,10·m^0,65 применялась при m до 20 (у 98,5 % допустимых m > 1,3, у 71 % η упиралась в 0,95) — исправлено ветвью
  1,28·(…) выше m = 1,3. Множитель θ = (T_гор − T4)/(T_стех − T4) к PF — придуман для бедных схем, в источнике его нет.
- **Ручной пересчёт трёх лучших вариантов автора** (idx 233, 21, 73) без кода модели — скорость в канале, диаметр

  исправлений — 4,4).

**Исправлено (выгоды даром и неравная основа):**
- рециркуляция FLOX ограничена стеснением соседними струями (плотные решётки — K = 0; редкие струи сохраняют K до 3);
- самостратификация затухает по длине смешения тем же законом, что и неравномерность;
- разброс диаметров печатных отверстий и каналов добавлен к неравномерности (тысячи отверстий 0,3–0,5 мм не дают
  идеальную раздачу даром);
- трение смесительного канала с шероховатостью по способу изготовления добавлено в потери (раньше длинные каналы
  смешивали без потерь);
- одна квадратура (5 узлов) для всех схем с узлами неравномерности;
- RDC не получает прироста давления (было ~10 % p3 при TRL 4: схема выполняла цель потерь даром);
- щелевая плёнка — в пределах ветви формулы;
- запас по самовоспламенению 3 и для дизеля;
- выносная и трубчатые камеры считают кожух с фланцем (как в составе цели parts_count);
- погасшая на 100/50 % зона не выполняет цели NOx и CO (раньше NOx ≈ CO ≈ 0 при несгоревшем метане проходили);
  в строке для воронки двигателя — флаги `burnt`.

**Готовность (TRL).** Штраф готовности в рейтинге номинальный: TRL входит только в оценку изготовимости (вес 0,10 ×
0,30), разница TRL 4 и 9 — не больше 0,019 оценки, а каталитическая (6) штрафуется меньше FLOX, RQL и TVC (5).
Детонационную и каталитическую схемы отсекают жёсткие цели через физические заместители (лишний клапан, индекс
пульсаций ×10 у RDC, ресурс катализатора 8000 ч и клапан предгорелки у CAT). Нужен ли явный порог TRL — решение
владельца.

## Ограничения и пробелы

- **Корреляции.** Lefebvre (стенка, PF, SMD), Holdeman, El-Shanawany — по памяти, первоисточники из среды не
  открылись. Константы смешения, рециркуляции, диффузора, катализатора, RDC — оценка.
- **Самостратификация и частичная нагрузка.** Затухание расслоения взято тем же законом, что и неравномерность при
  оптимальном проникновении; струи с малым J (частичная нагрузка) перемешиваются медленнее — если RANS это покажет,
  выгода частично вернётся. Неравномерность на 50 и 30 % у всех схем берётся по точке 100 % (J падает с расходом
  топлива) — одинаково для всех, оценка снизу.
- **Константы проверки скептика** — рост струи 0,22, разброс отверстий 0,025 / 0,008 / 0,05 мм, шероховатость 0,03 /
  0,005 мм, запас самовоспламенения 3 — оценка. Наименьшее печатное отверстие 0,3 мм и удаление порошка из тысяч
  отверстий не проверены.
- **Кожух выносной камеры** считается деталью, но его масса в `m_comb` не входит (картридж без кожуха).
- **Проскок.** Подбор K по одному факту «серийные DLE — 20–30 % H2» (по выдаче поиска). Числа Льюиса не учтены:
  допустимая доля H2 — оценка сверху.
- **Дизель.** Химия NOx переносится с равновесия Reitz на GRI, быстрый NOx не учтён — оценка снизу.
  Свойства жидкости — типовые (оценка).
- **Закалка CO плёнкой у стенки не моделируется** (0D). Пульсации — эвристический индекс, не расчёт. Ресурс
  каталитического блока 8000 ч — оценка.
- **Частичная нагрузка** — при постоянном расходе воздуха (как `targets_basis`). Для двухвальных пакетов надо
  считать иначе.
- **Давление топливного газа пакетов не опубликовано.** Окно 1,03–2,5·p3 и порог 1,3·p3 в Plug&Play — оценка;
  нужен запрос заказчику (`gtu-dropin`).
- **Границы посчитаны только для KV-3.** Для KV-1 … KV-7 надо добавить точки в `compute_boundary`.
- **Масса и детали — картридж без кожуха пакета.** Число деталей — правило подсчёта, не спецификация.
- **Каталог данных** (`node tools/build_catalog.mjs`) надо пересобрать после коммита, в чистой копии HEAD.
