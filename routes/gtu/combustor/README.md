## Метод: воронка

Каждый уровень дороже и точнее предыдущего. Он получает лучших с предыдущего уровня и отсекает по своим жёстким
целям. Код каждого уровня принимает `--n --shard --shards --out` (10–50 частей, разбиение одно — по индексу
варианта или задачи). У каждого уровня есть слияние с контролем полноты.

| уровень | вариантов | чем | что меряет | какие цели отсекает | где |
|---|---|---|---|---|---|
| L0 | 30 000 – 262 144 | сети реакторов Cantera (GRI-Mech 3.0, н-додекан Reitz) + корреляции | NOx, CO, срыв 30/50/100 %, проскок, самовоспламенение, дизель, стенка, PF, потери, детали, замена, Plug&Play | все 13 целей (облик) | AWS, 30–48 частей |
| калибровка | 2 эталона | Sandia D (RANS), PRECCINSTA (LES) | совпадение с опытом по критериям, записанным до прогона | ворота L1 и L3 | AWS |
| L1 | 500 | осесимметричный реагирующий RANS (reactingFoam LTS, k-ε, EDC v2005, GRI-Mech 3.0 + TDAC, P1): ячейка 100/50/30 % + труба 100 % | NOx, CO, полнота по нагрузке, неравномерность на срезе (вход), обратный ток, RTDF, T адиабатной стенки, потери | `nox_gas`, `co_gas`, `load_range`, `exit_uniformity` (RTDF), `pressure_loss`, `wall_life` | AWS, 25 частей |
| L2 | 30–50 (30) + активный дорасчёт | элемент 3D (дискретная струя) RANS; сектор трубы с теплообменом стенки (chtMultiRegionFoam); распыл дизеля (sprayFoam) | запас по срыву, допустимая доля H2 без проскока, S от дискретных струй, температура металла, дизель | `load_range`, `hydrogen`, `wall_life`, `diesel_dry`, `fuel_changeover` (дизель — после распыла) | AWS, 30 частей |
| L3 | 3–5 | LES элемента (WALE) + F(ω) + сеть акустических элементов; CalculiX картриджа | пульсации, рост мод, ресурс стенки и фланца | `combustion_dynamics`, `wall_life` (ползучесть) | AWS (LES), сессия (сеть, CalculiX) |
| каналы | 3 канала + 3 печатные структуры | SU2 discrete adjoint (диффузор), adjointOptimisationFoam (переход, улитка, коллектор — топология), TPMS + суррогат, TopOpt | потери полного давления, неравномерность на входе турбины, равномерность раздачи топлива, температура металла | `pressure_loss`, `exit_uniformity`, `fuel_valves` (один клапан) | AWS |

## Цели и что их меряет

Жёсткие цели (`targets.json → funnel_interface.hard`) — отсев. Ранжирующие (детали, потери, NOx, H2, замена) входят в
рейтинг с весами владельца (`merge_l0.WEIGHTS`).

| цель | предел | L0 | L1 | L2 | L3 |
|---|---|---|---|---|---|
| `nox_gas` / `co_gas` | 9 / 15 ppm при 15 % O2 на 50–100 % | сеть реакторов | RANS (100 % после разбавления, 50 % — выход ячейки) | элемент 3D | LES (средние) |
| `load_range` | 30–100 % малоэмиссионно, полнота ≥ 0,99 | сеть + запас по срыву | полнота и NOx/CO на 30 % | запас по срыву (цепочка) | — |
| `exit_uniformity` | PF ≤ 0,084, RTDF ≤ 0,05 | корреляция | RTDF трубы (PF осесимметрии = RTDF — оценка снизу) | — (сектор трубы — после словарей) | — |
| `pressure_loss` | ≤ 4 % | корреляции | смеситель и труба CFD + диффузор и переход L0 | — | каналы (adjoint) |
| `wall_life` | металл ≤ 1173 K, 30 000 ч | баланс стенки | баланс с T адиабатной стенки из CFD | chtMultiRegionFoam (после словарей) | CalculiX: ползучесть |
| `hydrogen` | ≥ 30 % H2 по объёму без переделки | корреляция проскока | — | цепочка H2 до проскока | — |
| `combustion_dynamics` | размах ≤ 1 % p3 | эвристический индекс | — | — | LES + сеть элементов |
| `diesel_dry`, `fuel_changeover` | NOx ≤ 42, CO ≤ 50 ppm без воды | Reitz → GRI | — | sprayFoam (после механизма) | — |
| `parts_count`, `cartridge_swap`, `fuel_valves` | ≤ 5 деталей, ≤ 2 ч, 1 клапан | правила модуля | без изменений | без изменений | топология коллектора — один вход |

## Уровень 0

### Пространство поиска (`comb_space.py`)

Дискретные оси (у каждой схемы свой список допустимых значений, `SCHEMES`):
- **схема:**
  - бедное предварительное смешение (LPP);
  - микросмешение (MM);
  - MILD/FLOX;
  - RQL;
  - захваченный вихрь (TVC);
  - каталитическая (CAT, со штрафом готовности TRL 6);
  - детонационная (RDC, со штрафом готовности TRL 4).
  Все TRL — оценка по `STATE_OF_ART.md`, разд. 4.
- **камера:** одна выносная / 6 трубчатых / кольцевая встроенная / противоточная;
- **форсунка:** закрутка / струи в сносящем потоке / микросмесители;
- **подача дизеля:** центробежная / пневматическая (LDI) / испарительная;
- **охлаждение стенки:** плёночное / многодырчатая эффузия / печатная решётка (последовательно, перепад `dp_wall`) / вкладыш CMC;
- **изготовление:** печатный картридж / литьё / гибрид;
- **пассивное деление топлива** (добавлено к заданию: по `targets_basis` один клапан держит пламя только на 83–100 %):
  - нет;
  - гидравлика: пилот через отверстие (расход ~ ΔP^0,5), основной контур через ламинарные капилляры (~ ΔP);
  - самостратификация струй: расслоение у входа канала затухает по длине смешения тем же законом exp(−l/2,5), что и
    неравномерность (проверка скептика: без затухания канал давал почти идеальное смешение на 100 % и полное
    расслоение на 30 % одновременно).

Непрерывные оси:
- число элементов и струй на элемент, диаметр топливной струи;
- крутка;
- доля воздуха в зоне горения и вспомогательная доля (пилот, полость, гашение);
- сила пассивного деления;
- времена пребывания: в зоне пламени, догорания, разбавления;
- L/D жаровой трубы; длина и диаметр трубы получаются из объёма зон;
- перепад на смесителе и на решётке стенки;
- пористость охлаждения;
- длина смешения.

Диаметр струи сэмплируется внутри окна, где давление топливного газа равно 1,03–2,5·p3 (оценка: давление топлива
в пакетах не опубликовано). Так выборка не тратится на заведомо негодные отверстия.

### Модель уровня 0 (`comb_crn.py`)

Вход — расчётная точка KV-3 (`frame3_point_results.json`, мягкий допуск):
- p3 = 1367,9 кПа, T3 = 683,5 K, воздух 25,17 кг/с, метан 0,3653 кг/с — совпадает с `targets_basis` до 6 знаков;
- 50 % нагрузки — T41 = 779,0 °C; 30 % — T41 = 683,6 °C. Допущения частичной нагрузки — как в `targets_basis`
  (постоянные частота и расход воздуха; оценка).

| часть | как считается | статус |
|---|---|---|
| смешение | неравномерность S = 0,01 + 0,5·f_C·exp(−l/2,5)·(1 − 0,3·(крутка − 0,4)+); f_C — отклонение C = (S/H)·J^0,5 от оптимума 2,5 (Holdeman, PECS 1993); в квадратуре — разброс раздачи 2σd/d по отверстиям (k_je на элемент) и каналам: σd печать 0,025 мм, сверление 0,008, литой канал 0,05 | константы и σd — оценка; форма Holdeman — по памяти, не сверено |
| зона пламени | PSR GRI-Mech 3.0, 5 узлов Гаусса — Эрмита по φ у всех схем (RQL — 1); рециркуляция продуктов догорания в корень пламени (закрутка K = 0,5·(S − 0,4)+; FLOX — унос по Ricou — Spalding 0,32·x/d·(ρ/ρ0)^0,5 до длины, на которой струя заполняет свою ячейку сечения, (D_ячейки − d0)/(2·0,22), не дальше 0,5·L_трубы, не больше 3) | форма Ricou — Spalding — по выдержке поиска; рост струи 0,22 — по памяти; остальное — оценка |
| догорание и разбавление | узлы раздельно идут 30 % времени догорания, затем вместе (бедные струйки дожигаются), затем воздух разбавления и PFR | оценка |
| RQL | богатая PSR → гашение тремя PSR (воздух тремя долями) → бедная PFR | оценка |
| TVC и гидравлический пилот | PSR полости (пилота) → её горячий газ входит в узлы основной зоны | оценка |
| CAT | бедная предгорелка до 723 K → превращение на катализаторе до 1173 K → гомогенное догорание PFR (задержка — расчётом) | пороги — оценка |
| RDC | сгорание при постоянном объёме (UV) вместо волны, NOx за τ_pz, расширение, PFR; прирост давления не засчитывается (ETA_PG = 0; было 0,05·(p_cv/p3 − 1) ≈ 10 % p3), p_cv/p3 — в результате; предел детонации φ ≥ 0,6 | грубая оценка |
| срыв | запас = τ / τ_погасания, бисекция PSR | расчёт |
| проскок | g_стенки(u_min) / (25·S_L²/α); u_min — вихревое ядро закрутки или след струи; K = 25 подобран так, что опорный серийный завихритель держит метан (запас 2,4) и 50 % H2 (1,6), но не 100 % H2 (0,33) | подбор — оценка; числа Льюиса не учтены |
| самовоспламенение | задержка (таблица) / время в смесителе; запас не меньше 3 и для газа (H2), и для испарительной подачи дизеля | расчёт; запас 3 — оценка |
| дизель | н-додекан, механизм Reitz (Fuel 136, 2014): равновесие → перенос на GRI → NOx в PFR; SMD — Lefebvre (центробежная) и El-Shanawany — Lefebvre (предплёночная); испарение по закону d²; доля диффузионного горения t_mix/(t_mix + t_chem) | формы — по памяти, не сверено; быстрый NOx не учтён (оценка снизу) |
| стенка | одномерный баланс в форме Lefebvre & Ballal (излучение газа 1 − exp(−290·P·L·(q·l_b)^0,5·T^−1,5), конвекция 0,020·k/D^0,2·(ṁ/Aμ)^0,8, плёнка — щелевая формула 1,10·m^0,65·(…) при m ≤ 1,3, выше 1,28·(…)); ε_стенки 0,7 | константа 290, l_b = 3,4·V/A и ε = 0,7 — по выдержке поиска; остальное по памяти |
| PF | θ·[1 − exp(−1/(A·L/D·ΔP_L/q_ref))] (A = 0,070 трубчатые, 0,050 кольцевые) ⊕ унаследованная неравномерность; θ — перенос с обычных камер на бедные | форма — по памяти, не сверено |

## Уровень 1: осесимметричный реагирующий RANS (`prepare_l1.py`, `comb_cfd.py`, `comb_l1.py`, `merge_l1.py`)

**Отбор.** `prepare_l1.py` берёт части уровня 0 (полные строки) или слитый файл. Отбор идёт так: сначала фронт
Парето, затем по кругу ниш «схема × тип камеры × форсунка × пассивное деление»; внутри ниши — по рейтингу
`merge_l0` (взвешенная оценка × штраф жёстких целей). При N = 300 ни один вариант не выполнил все жёсткие цели,
поэтому отбор идёт по рейтингу со штрафом, а не по допуску.

Варианты восстанавливаются по индексу (`comb_space.concept`). Для каждой нагрузки 100/50/30 % в вход записываются:
- p3, T3 и расходы;
- доля топлива пилота (`comb_crn.pilot_share`);
- доля воздуха, встречающая топливо при самостратификации (`comb_crn.strat_air_frac`);
- горячее поле зажигания — равновесие Cantera при φ зоны, T не ниже 1600 K (только начальное поле).

Отпечаток входов (sha256 строк) пишется в каждую часть. Проверено на отладке L0: 12 вариантов, 12 разных ниш,
повтор даёт тот же отпечаток (тест).

**Модель** (`comb_cfd.py`; клин 5°, ось z, радиус x, как учебник `SandiaD_LTS`; блочная сетка `blockMesh` по сетке
отрезков с маской):

*Ячейка* — один смесительный элемент в своей доле сечения жаровой трубы:
- радиус R = (A_L/(π·n_эл))^0,5;
- канал смешения d_air × l_mix·d_air (воздух с круткой — твёрдое вращение w = 2·S·u·r/R), затем срез и зона
  пламени и догорания; длина — по объёмам зон уровня 0;
- внешняя граница — симметрия (соседние элементы такие же) или стенка, если элемент один на трубу;
- по схеме: центральный пилот (гидравлическое деление), кольцевая полость у края ячейки (TVC), щель воздуха гашения
  (RQL);
- считается на 100, 50 и 30 %.

*Труба* — зона разбавления от конца догорания до выхода:
- форма: круг с осью (выносная, трубчатые) или кольцо вокруг оси двигателя (кольцевая, противоточная);
- вход — осреднённое по расходу состояние выхода ячейки при 100 % и слой охлаждающего воздуха у стенок (доля,
  вошедшая выше по течению);
- щели разбавления и ряды охлаждения на стенках;
- выход — профиль T для RTDF; стенка адиабатная, температура пристенного газа — температура адиабатной стенки.

*Решатель и модели* — те же, что у эталона Sandia D: `reactingFoam` с псевдовременем LTS, k-ε, EDC v2005, полный
GRI-Mech 3.0 с TDAC (DAC + ISAT), излучение P1. Порядок кейса (`Allrun` и `comb_l1.run_case`):
1. 1500 итераций без химии;
2. `setFields` — горячие продукты в зоне горения;
3. 4000 итераций с химией.

Сетки:
- coarse — у каждого варианта: ячейка в среднем 3 887 ячеек (до 5 060), труба 2 981 (до 5 076);
- medium — у каждого 10-го варианта: 9 911 (до 13 056).

Разница coarse/medium записывается.

*Топливо* — профиль смеси на входе канала: неравномерность S уровня 0 (Холдеман) косинусом по радиусу и
самостратификация — топливо в доле сечения a_eff. Средняя φ по расходу воздуха совпадает с заданной (тест, допуск
2e-3). **L1 не уточняет смешение дискретных струй** — это делает элемент 3D уровня 2. Кольцевая щель (`RING = False`)
выключена после обкатки (ниже).

**Итоги кейса** (`comb_post.py`; читает сетку и поля ascii, работает и на 1912, и на v2512):
- выход — средние по расходу T и состав;
- NOx = NO + NO2 и CO в ppm сухого газа при 15 % O2 (при O2 сухом > 20 % приведение не делается — на выходе
  воздух);
- полнота сгорания по теплоте сгорания CH4, CO, H2 (значения — `comb_bc_results.json`);
- RTDF по радиальному профилю;
- полное давление на входах и выходе и его потеря;
- баланс массы;
- сходимость: между двумя последними записями T < 0,2 %, NOx < 5 %, CO < 10 % и баланс массы < 1 %;
- ячейка: σ/среднее φ (по атомам C, H, O) на срезе канала; T в канале (проскок или самовоспламенение — выше T3 на
  200 K); обратный ток на 2 калибрах за срезом; массы области и горячей зоны;
- труба: температура пристенного газа по длине.

**Слияние** (`merge_l1.py`) — полнота, как у `merge_l0`: отпечатки входов и кода, итерации, сетка, части 0..S-1,
позиции = range(n). Код 2 — не хватает части. Дальше по каждому варианту:
- **второй способ**: реактор Cantera GRI-Mech 3.0 постоянного давления от равновесия при φ среза (NO = 0) на время
  пребывания горячей зоны CFD. Отношение NOx CFD / Cantera вне 0,5–2 — флаг «разбор»: вариант не идёт на L2, число
  не публикуется;
- **стенка**: баланс в форме `comb_crn.wall_temperature` с температурой адиабатной стенки из CFD;
- **потери** = диффузор + переход (L0) + max(перепад смесителя L0, потери ячейки CFD) + потери трубы CFD + решётка
  стенки. Потеря входа в канал (сжатие струи) в ячейке не разрешена и остаётся по L0;
- **цели** `nox_gas`, `co_gas`, `load_range`, `exit_uniformity`, `pressure_loss`, `wall_life` пересчитываются;
  остальные — статус L0;
- **рейтинг** — веса `merge_l0`, КПД и NOx по L1, штраф exp(−2·Σ нарушений).

На выходе — `select_l2` (30 по кругу ниш) и `feed_to_engine_funnel` (dp, NOx, CO, RTDF, стенка — L1; габарит,
масса, детали — L0).

**Критерии прохода на L2:**
- кейс сошёлся;
- флага сверки нет;
- горит на 100 и 50 % (полнота ≥ 0,99);
- NOx ≤ 9, CO ≤ 15 ppm;
- в остальном — рейтинг.

Стоп пакета: сошлось меньше 70 % кейсов или флагов сверки больше 10 % — второй проход (+3000 итераций с последней
записи) и разбор, не L2.

**Местная обкатка** (`comb_l1_smoke_results.json`; apt-OpenFOAM 1912, 4 общих ядра под нагрузкой 17–34, вариант
idx 233 — FLOX, выносная, 275 элементов):
- *Версия 1*: топливо — кольцевой щелью в канале шириной 48 мкм (2 ячейки), чтобы сохранить J варианта.
  - Сетка, решатель (600 + 3000 итераций, 23 мин), `setFields` и разбор прошли.

    0,2 м из 0,59 м.
- *Исправление*:
  - щель выключена — топливо профилем смеси;

- *Версия 2* (тот же вариант):

## Уровень 2: трёхмерные секторы и запасы (`comb_cfd3d.py`, `comb_l23.py --level L2`, `l2_active.py`)

- **Элемент 3D** (готов к запуску). Один смесительный элемент, сектор 360/k_je с одной топливной струёй:
  - циклические границы при крутке; при k_je = 1 или без крутки — половина с плоскостями симметрии;
  - струя — квадратное отверстие той же площади на стенке канала, скорость по расходу и составу;
  - сетка — `blockMesh` с дугами: в среднем 45 413 ячеек (до 102 500; проверено `checkMesh` на трёх вариантах);
  - модели — как L1, RANS LTS;
  - на вариант 4 задачи по 16 ядер (`decomposePar`, `mpirun`), часть = вариант: 50 % и 30 %; **запас по срыву** — 100 %, затем рестарты
    с топливом ×0,9 … ×0,5 до погасания (полнота < 0,9, или T_max < T3 + 300 K, или разбаланс > 5 %); запас =
    1/последний горящий множитель; **проскок** — 100 %, затем доля H2 0,3; 0,5; 0,7; 1,0 по объёму при той же
    теплоте топлива до T в канале > T3 + 200 K.
- **Сектор трубы с теплообменом стенки** (сетка готова, словари — нет):
  - газ и стенка — cellZone при `blockMesh`;
  - ячейки стенки в отверстии разбавления и в щелях охлаждения переводятся в газ (`topoSet`); затем
    `splitMeshRegions`, а наружные грани газа становятся входами (`createPatch`);
  - проверено на 1912 (`Allmesh`, idx 233): газ 73 356 ячеек, стенка 6 504, `inlet_dil` 18 граней, `inlet_cool`
    240, стык `gas_to_solid`, обе области `Mesh OK`;
  - решатель — `chtMultiRegionFoam`: газ реагирующий; стенка `heSolidThermo`; стык
    `compressible::turbulentTemperatureRadCoupledMixed`; снаружи — теплоотдача к воздуху кожуха (h и T3 из
    `comb_crn.wall_temperature`);
  - **не готово**: словари областей (`constant/gas`, `constant/solid`, `0/gas`, `0/solid`, `regionProperties`) и
    свойства печатного сплава k(T), cp(T) с источником.
- **Распыл дизеля** (`sprayFoam`, `comb_cfd3d.spray_dicts`):
  - облако `sprayCloud`, жидкость C12H26;
  - впрыск по типу подачи: центробежная — LISA; пневматическая (LDI) и испарительная — `ReitzDiwakar` или без
    распада;
  - **не готово**: механизм н-додекана Reitz в формате OpenFOAM (yaml2ck → chemkinToFoam с тремя правками навыка);
    NOx — постобработка Cantera GRI по зонам (в Reitz нет азотной химии).
- **Активный дорасчёт по нейросетевой модели** (`l2_active.py` → `platform/surrogate/surrogate.py`):
  - на семейство «схема × камера × форсунка» — `problem.json`: непрерывные оси `comb_space` в границах схемы и
    форсунки; выходы dp, NOx_100, CO_100, NOx_30, RTDF, T_metal;
  - модель — ансамбль MLP + гауссовский процесс, проверка по блокам;
  - `next`: ожидаемое улучшение по потерям (КПД) × вероятность выполнить NOx_100 ≤ 9, CO_100 ≤ 15, NOx_30 ≤ 15,
    RTDF ≤ 0,05, T_metal ≤ 1173 K;
  - точки становятся вариантами (дискретные оси семейства + `comb_space.derive` и `check`); сначала идут на L1, потом
    на L2;
  - 3 порции по 12 точек; стоп — максимум EI меньше допуска две порции подряд (навык `surrogate-opt`);
  - прогноз модели — не результат.
- **Критерии прохода на L3:**
  - запас по срыву ≥ 1,5 (оценка; у серийных DLE — не опубликовано);
  - H2 ≥ 0,3 по объёму без проскока;
  - NOx и CO в норме на 3D;
  - (после словарей) металл ≤ 1173 K, дизель — NOx ≤ 42 ppm.

  Меньше 3 прошедших — стоп и пересмотр схем на уровне 0.

## Уровень 3: LES, термоакустика, прочность (`comb_l23.py --level L3`, `comb_acoustic.py`, CalculiX)

- **LES элемента:**
  - тот же сектор, канал и 35 % длины ячейки: в среднем 62 442 ячейки (до 143 220) — сетка ограничена тем, что кейс
    должен уложиться в сторож 720 мин на одной машине;
  - `reactingFoam` нестационарно: WALE, шаг по Co ≤ 0,5, 8 + 6 времён протекания зоны пламени;
  - датчики давления (срез, зона пламени, выход), интеграл тепловыделения, средние поля;
  - второй кейс — широкополосное возбуждение расхода воздуха ±5 % (59 синусов 50–1500 Гц) для F(ω);
  - на машину один кейс на 64 ядрах; машина не читает S3, поэтому кейс обязан уложиться в сторож (720 мин),
    продолжения на другой машине нет.
- **Сеть акустических элементов** (`comb_acoustic.py`, метод Dowling & Stow 2003, OSCILOS — по памяти, тексты не
  открывались):
  - трубы с плоскими волнами и средним течением; компактное пламя (A₂u₂' = A₁u₁'·(1 + (T₂/T₁ − 1)·F));
  - концы: вход за компрессором R = 1, выход — сопло Марбла — Кандела (по памяти, не сверено);
  - моды — нули определителя в комплексной плоскости. Самопроверка (`comb_acoustic_results.json`): закрытая —
    открытая и закрытая — закрытая труба, скачок температуры против аналитики (совпадение до 1e-12 по частоте), знак
    роста трубы Рийке — всё прошло;
  - пример на четырёх вариантах отбора L0 при n = 1 и τ = время смешения + половина времени зоны пламени — первые
    моды 68–274 Гц, у первой моды рост 114–210 1/с. Это иллюстрация метода: затухание отверстий и стенок не учтено,
    n = 1 не измерено. На L3 F(ω) берётся из LES (`identify_ftf`, КИХ-фильтр — проверен на SYNTHETIC n–τ: |F| и фаза
    точно);
  - критерий: рост всех мод ≤ 0 с F(ω) из LES и размах пульсаций LES ≤ 1 % p3.
- **Прочность и ползучесть картриджа** (CalculiX, навык `calculix-rotor`):
  - осесимметричный CAX8 жаровой трубы и фланца;
  - температура — из сектора трубы L2 (после словарей); давление — перепад на стенке;
  - Нортон `*CREEP` в `*VISCO`; Ларсон — Миллер;
  - печатные сплавы (Hastelloy X, IN625, IN718 после HIP) и литьё КНР (`casting-spec`);
  - констант ползучести печатных сплавов в `platform/fea/materials.json` нет — ресурс без них не выдаётся (раздел «Ограничения и
    пробелы»);
  - считается в сессии (минуты), AWS не нужен.

## Стык с воронкой двигателя

- `merge_l0.py` пишет в `feed_to_engine_funnel.best` лучший вариант каждой пары «схема × тип камеры».
- `merge_l1.py` пишет то же с числами L1: `dp_comb`, NOx/CO 100 %, NOx 50/30 %, RTDF, `T_metal_max_K`, плюс
  габарит, масса, детали и число элементов L0.

Поля — `targets.json → funnel_interface`. Они заменяют заглушки `../funnel/funnel_space.py`:
- потери 4 / 5 %;
- D_comb = 1,1·Dc;
- L_comb = 0,6·D_comb;
- масса трубы по 2 мм;

- TVC: деление (нет / гидравлика) × струи;

Первая проба с одним элементом на вариант (300 вариантов, код до сочетаний — не сохранён) не дала ни одного
варианта с новой целью: ни один элемент в одиночку не перераспределял топливо как нужно. Поэтому перебор ищет и
сочетания.

**Правила допустимости, добавленные в v2:**
- **ТОПЛИВО.** Нужно давление коллектора в окне 1,03–2,5·p3, при котором диаметры струй всех контуров в диапазоне
  типа форсунки и способа изготовления.
- **ОБРАТНЫЙ_ТОК.** Давление коллектора над давлением за соплами основного контура — не меньше 1 % p3 на каждой
  нагрузке. Это допустимый размах пульсаций (цель combustion_dynamics). Иначе воздух войдёт в топливный контур:
  именно этот запас ограничивает сдвиг давления.
- **ЭЛЕМЕНТЫ_КОНТУРОВ.** На каждый контур должен приходиться хотя бы один смеситель.

**Индекс пульсаций** v1 умножен на «жёсткость» топливной подачи: (0,03/ΔPтоп_мин)^0,5, где ΔPтоп_мин — наименьший
по нагрузкам перепад топлива в долях p3, взвешенный по расходу контуров; константа 0,03 — оценка. Без этого схема
со сдвигом давления получала бы выигрыш даром.

**Нагрузки** — 100 / 75 / 50 / 30 %. Точка 75 % посчитана тем же способом, что точки v1
(`comb_bc_v2_results.json`). Самопроверка: точка 50 % пересчитана кодом v2 и совпала с v1 до 4·10⁻⁶.

**Согласованное смешение.** Скорость воздуха на каждой нагрузке берётся при неизменной геометрии смесителя. Давления
и расходы контуров — из решения коллектора. По ним считаются J, неравномерность S каждого контура, расслоение и
проскок — для каждого контура на каждой нагрузке. Таблица S_L снята при p3 и T3 точки 100 %, поэтому на малой
нагрузке запас по проскоку занижен (оценка).

**Сеть реакторов на каждой нагрузке:**
1. опорная зона — пилот, полость или группа A: 5 узлов, у каждого свой реактор идеального смешения;
2. её горячий газ уходит в узлы основной зоны (для пилота и полости);
3. основная зона: 5 узлов, расслоение, рециркуляция;
4. совместное догорание; туда же идёт воздух, не встретивший топливо;
5. разбавление и реактор вытеснения.

Запасы по срыву считаются двумя способами: опорной зоны (margin_lbo) и наименьший по всем зонам (margin_all). Отсев
ПОГАСАНИЕ_100 срабатывает, если на 100 % гаснет любая зона.

  (медиана 0,21). Её топливо не догорает в горячем газе пилота, полости или группы A: медиана полноты на 30 % — 0,27,
  наибольшая — 0,996.
- **Самостратификация.** На 30 % наименьшая доля воздуха, встречающего топливо, — от 0,21 (TVC) до 0,50 (MM). Но
  на 100 % при C < C_OPT расслоение даёт богатую смесь и NOx.
- **Что ограничивает новую цель у 134 допустимых:** NOx — 38, полнота — 38, CO — 32, срыв — 26.
- **Ближайший вариант без RQL** — idx 9 (MM, каналы + струи), значение 21,4: CO на 30 % — 1069 ppm, NOx на 100 % —
  83 ppm, полнота на 30 % — 0,985.

**Чувствительность к закону затухания при малом J.** Та же выборка посчитана при β = 0 (затухание как в v1), 1 и 2:
- новая цель — 0 / 0 / 0;
- устойчиво 30–100 % — 38 / 39 / 39;
- в ячейке LPP + струи наименьшая доля воздуха, встречающего топливо на 30 %, — 0,96 / 0,41 / 0,23, лучшее значение
  новой цели — 100 / 66,9 / 39,3.

Закон влияет заметно, но держателей при N = 300 не даёт. Поэтому на AWS он считается отдельными сериями.

### AWS: `jobs_aws_comb_l0_v2.json` (`make_jobs_l0_v2.py`)

**Объём — по правилу «до сходимости доли», записанному до прогона (оценка):**
- **К1.** Ноль держателей в пробе → N ≥ 3/10⁻⁵ = 300 000 (правило трёх). Доля ниже 10⁻⁵ для уровня облика
  несущественна.
- **К2.** Если держатели есть — не меньше 100 держателей. Здесь не применяется.
- **К3.** Доля «устойчиво 30–100 %» в самой узкой ячейке «схема × сочетание» без RQL: 25 событий, то есть
  относительная ошибка не больше 20 %. Доля по пробе — 1 из 241, ячейка — 1/60 выборки → N ≥ 361 500.

Итог: **N = 2^19 = 524 288**. Сходимость проверит слияние: доля по вложенным префиксам Соболя 2^k (вложенность
проверена). Если на 2^19 держателей нет, верхняя граница доли — 5,7·10⁻⁶.

**Серии:**
- основная — N = 524 288, 6 задач × 8 частей (48 частей по индексу i % 48);
- чувствительность к β (0 и 2) — по 131 072 варианта, 4 задачи × 12 частей;

  (cantera 3.2.0, numpy 2.5.3, scipy 1.18.1), поэтому ключ границ совпадает.

**Смета:**
- время варианта на машине — 0,99 с × 1,116 = 1,10 с; 1,116 — отношение времени на AWS к процессорному времени в
  сессии у v1 (оценка);
- ядро-часов — 160 (основная серия) + 40 + 40;
- сторож — 65 и 35 мин.

**Проверки пакета:**
- `runner.py plan` — код 0, прогноз раннера (верхняя граница) 19,23 долл. при 0,75 долл./ч;
- ожидаемо 3,65 долл. (оценка), это 0,2 % потолка 2000 долл.: CPU-серия, отдельного вопроса не нужно;
- мини-проверка: команды основной серии при n = 96 в копии ветки — 6 задач с кодом 0, 48 частей, слияние полное.

**Порядок для сессии с ключами:**

4. Команды блока `merge` файла задач → `l0_aws_v2/`. Слиянию нужно не меньше 6 ГБ свободной памяти: замер пика —

### Ограничения v2 и что дальше

**Ограничения:**
- Закон затухания при малом J (β) — оценка, сильнее всего влияет на самостратификацию; проверка — уровень 1.
- Пористая вставка: задан только закон сопротивления, проницаемость и размер не считались.
- Сдвиг давления ограничен перепадом смесителя (впрыск у входа или выхода канала). Сопло Вентури с восстановлением
  давления дало бы больше — не считалось.
- Пилотные смесители — того же типа и канала, что основные.
- Взаимное поджигание групп A и B не учтено.
- Нагрев стенки канала рециркуляции не моделируется.
- Стенка считается только на 100 %: горячее пятно пилота на малой нагрузке не моделируется.
- Константа жёсткости 0,03 p3 — оценка; TRL элементов — оценка.

**Что дальше:**
- Серия AWS v2 и слияние.
- Если держателей нет и на 2^19, уровень 0 скажет: в этих законах пассивный элемент с одним клапаном 30–100 % с
  низкими выбросами не держит. Тогда:
  - уровень 1 (RANS) для ближайших вариантов каждой ячейки — проверка закона при малом J и догорания основной зоны;
  - решение владельца о постановке — только окном, через основную сессию.
- Расширение выборки до 2^20 может переиспользовать первые 2^19 строк (префиксы вложены), но нужен ключ начала
  индексов у `comb_l0_v2.py` — не сделан.

## Ограничения и пробелы

**Уровни 1–3 и каналы (этот выпуск):**
- **Шаблон L1 не доведён до сходимости.** Первая версия не сошлась (см. обкатку); исправленная на момент записи
  считалась. Сходимость, устойчивость сглаживания шага LTS 0,1 и maxCo 0,3 на разных схемах, второй проход — проверить
  на v2512 до пакета.
- **Смешение дискретных струй в L1 не уточняется.** Профиль смеси берёт S уровня 0. Уточнение — элемент 3D уровня 2.
- **PF осесимметрии = RTDF** — оценка снизу настоящего PF; окружная неравномерность — L2 (сектор трубы).
- **Охлаждение в трубе L1 — нормальный вдув щелями** (как эффузия), а не плёнка вдоль стенки. Потеря входа в канал
  смешения не разрешена (остаётся по L0).
- **Пилот, полость TVC, гашение RQL в ячейке — кольцевые аналоги** в осесимметрии (оценка формы).
- **Не готово к запуску:** словари областей и свойства печатного сплава для сектора трубы с теплообменом; механизм
  н-додекана Reitz в формате OpenFOAM для распыла; геометрия и данные PRECCINSTA; генератор геометрии каналов
  (диффузор, переход, улитка); константы ползучести печатных сплавов для CalculiX.
- **Образ OpenFOAM.** `opencfd/openfoam-default:2512` — тег есть на Docker Hub (23.01.2026, 0,48 ГБ). Не проверено:
  есть ли в нём учебники (сценарий Sandia D тогда качает файлы v2512 с GitLab) и python3 (ставится `apt-get` в
  `container_setup`). Словари сверены по исходникам v2512/v2606, прогоны — только на 1912.
- **Время ячейки·итерации** — 1912 на чужой нагрузке. На c7a не мерено. LES: шагов 50 000 и эффективность 0,75 —
  оценка. Кейс LES обязан уложиться в сторож 720 мин: машина не читает S3, продолжения нет.
- **Запас по срыву ≥ 1,5 и порог «флаг сверки» 0,5–2** — критерии проекта (оценка).
- **Сеть акустических элементов** — продольные моды. Азимутальные моды кольцевой камеры — только частоты
  f = m·c/(π·D_m). Затухание отверстий не моделируется. Сопло Марбла — Кандела и метод Dowling & Stow — по памяти.
- **Цены итерации каналов.** SU2 — по смете другого пакета. Сопряжённое = 1,5 прямого — оценка. Дискретное
  сопряжённое SU2 — только со сборкой `-Denable-autodiff=true`.
- **Каталог данных** (`node tools/build_catalog.mjs`) — пересобрать после коммита, в чистой копии HEAD.

**Уровень 0 (без изменений):**

- **Корреляции.** Lefebvre (стенка, PF, SMD), Holdeman, El-Shanawany — по памяти, первоисточники из среды не
  открылись. Константы смешения, рециркуляции, диффузора, катализатора, RDC — оценка.
- **Самостратификация и частичная нагрузка.** Затухание расслоения взято тем же законом, что и неравномерность при
  оптимальном проникновении; струи с малым J (частичная нагрузка) перемешиваются медленнее — если RANS это покажет,
  выгода частично вернётся. Неравномерность на 50 и 30 % у всех схем берётся по точке 100 % (J падает с расходом
  топлива) — одинаково для всех, оценка снизу.
- **Константы проверки скептика** — рост струи 0,22, разброс отверстий 0,025 / 0,008 / 0,05 мм, шероховатость 0,03 /
  0,005 мм, запас самовоспламенения 3 — оценка. Наименьшее печатное отверстие 0,3 мм и удаление порошка из тысяч
  отверстий не проверены.
- **Кожух выносной камеры** считается деталью, но его масса в `m_comb` не входит (картридж без кожуха).
- **Проскок.** Подбор K по одному факту «серийные DLE — 20–30 % H2» (по выдаче поиска). Числа Льюиса не учтены:
  допустимая доля H2 — оценка сверху.
- **Дизель.** Химия NOx переносится с равновесия Reitz на GRI, быстрый NOx не учтён — оценка снизу.
  Свойства жидкости — типовые (оценка).
- **Закалка CO плёнкой у стенки не моделируется** (0D). Пульсации — эвристический индекс, не расчёт. Ресурс
  каталитического блока 8000 ч — оценка.
- **Частичная нагрузка** — при постоянном расходе воздуха (как `targets_basis`). Для двухвальных пакетов надо
  считать иначе.
- **Давление топливного газа пакетов не опубликовано.** Окно 1,03–2,5·p3 и порог 1,3·p3 в Plug&Play — оценка;
  нужен запрос заказчику (`gtu-dropin`).
- **Границы посчитаны только для KV-3.** Для KV-1 … KV-7 надо добавить точки в `compute_boundary`.
- **Масса и детали — картридж без кожуха пакета.** Число деталей — правило подсчёта, не спецификация.
- **Каталог данных** (`node tools/build_catalog.mjs`) надо пересобрать после коммита, в чистой копии HEAD.
