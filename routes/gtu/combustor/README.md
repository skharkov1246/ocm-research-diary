# Камера сгорания KV — воронка, уровень 0

Узел трека `gas-turbine` (двигатель-заменитель KV, issue #59). Задача владельца 14.11.2026: переработать горение,
форсунки и каналы перебором на AWS так, чтобы камера была проще и лучше существующих. Приоритеты: минимум деталей
(главное), Plug&Play в пакет Solar/Siemens (один регулирующий клапан на топливо), монтаж и ремонт «хоть уборщиком»
(сменный картридж), затем КПД и размер. Цели камеры — `targets.json` (обоснование — `targets_basis.py`,
`STATE_OF_ART.md`).

Состояние на 14.11.2026: код уровня 0, тесты (17 passed) и локальная отладка готовы. Пакет задач для AWS проверен
командой `plan` раннера (без AWS). Живого запуска не было: его делает отдельная сессия с ключами. Ничего не коммитилось.
Все числа ниже — уровень облика (0D-сети реакторов + корреляции), то есть **оценка** для отбора на L1 (RANS).
Это не прогноз выбросов конструкции.

## Запуск

```bash
cd routes/gtu/combustor
python3 comb_crn.py --bc                                  # пересчёт границ и таблиц (~4,5 мин на 4 ядрах)
python3 comb_l0.py --n 300 --shard 0 --shards 4 --out /tmp/l0 --workers 4
python3 merge_l0.py /tmp/l0 --out /tmp/l0/merged.json     # код 0 - полно, 2 - не хватает части
python3 -m pytest -q test_comb_l0.py                      # 17 passed, ~30 с
python3 make_jobs_l0.py                                   # jobs_l0.json + смета (runner.py plan, без AWS)
```

## Пространство поиска (`comb_space.py`)

Дискретные оси (у каждой схемы свой список допустимых значений, `SCHEMES`):
- **схема:**
  - бедное предварительное смешение (LPP);
  - микросмешение (MM);
  - MILD/FLOX;
  - RQL;
  - захваченный вихрь (TVC);
  - каталитическая (CAT, со штрафом готовности TRL 6);
  - детонационная (RDC, со штрафом готовности TRL 4).
  Все TRL — оценка по `STATE_OF_ART.md`, разд. 4.
- **камера:** одна выносная / 6 трубчатых / кольцевая встроенная / противоточная;
- **форсунка:** закрутка / струи в сносящем потоке / микросмесители;
- **подача дизеля:** центробежная / пневматическая (LDI) / испарительная;
- **охлаждение стенки:** плёночное / многодырчатая эффузия / печатная решётка (последовательно, перепад `dp_wall`) / вкладыш CMC;
- **изготовление:** печатный картридж / литьё / гибрид;
- **пассивное деление топлива** (добавлено к заданию: по `targets_basis` один клапан держит пламя только на 83–100 %):
  - нет;
  - гидравлика: пилот через отверстие (расход ~ ΔP^0,5), основной контур через ламинарные капилляры (~ ΔP);
  - самостратификация струй.

Непрерывные оси:
- число элементов и струй на элемент, диаметр топливной струи;
- крутка;
- доля воздуха в зоне горения и вспомогательная доля (пилот, полость, гашение);
- сила пассивного деления;
- времена пребывания: в зоне пламени, догорания, разбавления;
- L/D жаровой трубы; длина и диаметр трубы получаются из объёма зон;
- перепад на смесителе и на решётке стенки;
- пористость охлаждения;
- длина смешения.

Диаметр струи сэмплируется внутри окна, где давление топливного газа равно 1,03–2,5·p3 (оценка: давление топлива
в пакетах не опубликовано). Так выборка не тратится на заведомо негодные отверстия.

## Модель уровня 0 (`comb_crn.py`)

Вход — расчётная точка KV-3 (`frame3_point_results.json`, мягкий допуск):
- p3 = 1367,9 кПа, T3 = 683,5 K, воздух 25,17 кг/с, метан 0,3653 кг/с — совпадает с `targets_basis` до 6 знаков;
- 50 % нагрузки — T41 = 779,0 °C; 30 % — T41 = 683,6 °C. Допущения частичной нагрузки — как в `targets_basis`
  (постоянные частота и расход воздуха; оценка).

| часть | как считается | статус |
|---|---|---|
| смешение | неравномерность S = 0,01 + 0,5·f_C·exp(−l/2,5)·(1 − 0,3·(крутка − 0,4)+); f_C — отклонение C = (S/H)·J^0,5 от оптимума 2,5 (Holdeman, PECS 1993) | константы — оценка; форма Holdeman — по памяти, не сверено |
| зона пламени | PSR GRI-Mech 3.0, 5 или 3 узла Гаусса — Эрмита по φ; рециркуляция продуктов догорания в корень пламени (закрутка K = 0,5·(S − 0,4)+; FLOX — унос по Ricou — Spalding 0,32·x/d·(ρ/ρ0)^0,5, не больше 3) | форма Ricou — Spalding — по выдержке поиска; остальное — оценка |
| догорание и разбавление | узлы раздельно идут 30 % времени догорания, затем вместе (бедные струйки дожигаются), затем воздух разбавления и PFR | оценка |
| RQL | богатая PSR → гашение тремя PSR (воздух тремя долями) → бедная PFR | оценка |
| TVC и гидравлический пилот | PSR полости (пилота) → её горячий газ входит в узлы основной зоны | оценка |
| CAT | бедная предгорелка до 723 K → превращение на катализаторе до 1173 K → гомогенное догорание PFR (задержка — расчётом) | пороги — оценка |
| RDC | сгорание при постоянном объёме (UV) вместо волны, NOx за τ_pz, расширение, PFR; прирост давления 0,05·(p_cv/p3 − 1); предел детонации φ ≥ 0,6 | грубая оценка |
| срыв | запас = τ / τ_погасания, бисекция PSR | расчёт |
| проскок | g_стенки(u_min) / (25·S_L²/α); u_min — вихревое ядро закрутки или след струи; K = 25 подобран так, что опорный серийный завихритель держит метан (запас 2,4) и 50 % H2 (1,6), но не 100 % H2 (0,33) | подбор — оценка; числа Льюиса не учтены |
| самовоспламенение | задержка (таблица) / время в смесителе | расчёт |
| дизель | н-додекан, механизм Reitz (Fuel 136, 2014): равновесие → перенос на GRI → NOx в PFR; SMD — Lefebvre (центробежная) и El-Shanawany — Lefebvre (предплёночная); испарение по закону d²; доля диффузионного горения t_mix/(t_mix + t_chem) | формы — по памяти, не сверено; быстрый NOx не учтён (оценка снизу) |
| стенка | одномерный баланс в форме Lefebvre & Ballal (излучение газа 1 − exp(−290·P·L·(q·l_b)^0,5·T^−1,5), конвекция 0,020·k/D^0,2·(ṁ/Aμ)^0,8, плёнка — щелевая формула); ε_стенки 0,7 | константа 290, l_b = 3,4·V/A и ε = 0,7 — по выдержке поиска; остальное по памяти |
| PF | θ·[1 − exp(−1/(A·L/D·ΔP_L/q_ref))] (A = 0,070 трубчатые, 0,050 кольцевые) ⊕ унаследованная неравномерность; θ — перенос с обычных камер на бедные | форма — по памяти, не сверено |
| потери давления | диффузор (M3 = 0,2, K по типу камеры) + смеситель + решётка + горячие (Рэлей) + переходный канал − прирост RDC; цена — 49,4 кВт и 0,27 п.п. КПД на процент (`targets_basis`) | оценка + расчёт |
| модуль | правила подсчёта деталей, сварок, центровок; время замены по типу камеры; Plug&Play (клапаны, давление топлива, смена топлива, стык); изготовимость по форме `make_model` воронки двигателя (принтеры — по выдержке поиска) | оценка |
| цели | все 13 целей `targets.json` с величиной, пределом и нарушением; жёсткие — по `funnel_interface.hard` | — |

Сайты с первоисточниками корреляций из этой среды не открылись (`apps.dtic.mil`, `www.conference.isabe.org` —
нет в разрешённых адресах). Формы Lefebvre, Holdeman и El-Shanawany записаны по памяти и помечены «не сверено».

## AWS: `jobs_l0.json`

- **Пакет.** 30 задач `comb-l0-p00` … `p29`, по 1000 вариантов KV-3 на задачу:
  - c7a.16xlarge (запасной c7i.16xlarge), al2023;
  - Python 3.13 через uv;
  - пакеты закреплены как в отладке (`cantera==3.2.0`, `numpy==2.5.3`, `scipy==1.18.1`), поэтому ключ границ
    совпадает и части не пересчитывают таблицы;
  - число процессов — `$NPROC`;
  - сторож 25 мин: подготовка 10 + запас на пересчёт границ 6 + 3 × счёт 0,17 + выгрузка 8.
- **Смета.** Счёт всего пакета — 5,5 ядро-часа. `runner.py plan` (код 0) даёт прогноз пакета по формуле раннера
  (верхняя граница):
  - **20,20 долл.** при цене спота 0,955 долл./ч — наибольшая по зонам в живом пробном прогоне 14.11.2026, навык
    `aws-gtu-runs`;
  - **31,64 долл.** при 1,5 долл./ч.
  Это 1,0–1,6 % общего потолка 2000 долл. Очередь: 1920 vCPU пакета больше квоты 384, поэтому одновременно идут
  6 машин.
- **Перерасход машин.** Счёт части занимает около 10 с, остальное время машины — подготовка. Тот же N уложился бы
  в одну машину (около 5 мин счёта). 30 частей взяты по заданию; при нехватке бюджета можно взять 10 частей
  (нижняя граница правила).
- **Порядок живого запуска.** Отдельная сессия в окружении Coldun, навык `aws-gtu-runs`:
  1. ветку с кодом и `comb_bc_results.json` запушить;
  2. `run` без `--live` (проверка прав);
  3. `--live` — только с разрешения владельца;
  4. затем:
     `python3 routes/gtu/combustor/merge_l0.py runs/<run_id> --out routes/gtu/combustor/comb_l0_KV-3_results.json`.

## Стык с воронкой двигателя

`merge_l0.py` пишет в `feed_to_engine_funnel.best` лучший вариант каждой пары «схема × тип камеры». Поля
(`targets.json → funnel_interface`):
- `dp_comb`, `D_comb`, `L_comb`, `m_comb`, `n_inj`;
- `parts`;
- NOx и CO на 100 / 50 / 30 %;
- `PF`, `RTDF`, `T_metal_max_K`;
- `fuel_valves`, `H2_vol_max`;
- NOx дизеля на 100 / 50 %;
- `cartridge_swap_h`, `V_L`.

Они заменяют заглушки `funnel_space.py`: потери 4 / 5 %, D_comb = 1,1·Dc, L_comb = 0,6·D_comb, масса трубы по 2 мм,
число форсунок. Файлы воронки двигателя здесь не правились.

## Ограничения и пробелы

- **Корреляции.** Lefebvre (стенка, PF, SMD), Holdeman, El-Shanawany — по памяти, первоисточники из среды не
  открылись. Константы смешения, рециркуляции, диффузора, катализатора, RDC — оценка.
- **Проскок.** Подбор K по одному факту «серийные DLE — 20–30 % H2» (по выдаче поиска). Числа Льюиса не учтены:
  допустимая доля H2 — оценка сверху.
- **Дизель.** Химия NOx переносится с равновесия Reitz на GRI, быстрый NOx не учтён — оценка снизу.
  Свойства жидкости — типовые (оценка).
- **Закалка CO плёнкой у стенки не моделируется** (0D). Пульсации — эвристический индекс, не расчёт. Ресурс
  каталитического блока 8000 ч — оценка.
- **Частичная нагрузка** — при постоянном расходе воздуха (как `targets_basis`). Для двухвальных пакетов надо
  считать иначе.
- **Давление топливного газа пакетов не опубликовано.** Окно 1,03–2,5·p3 и порог 1,3·p3 в Plug&Play — оценка;
  нужен запрос заказчику (`gtu-dropin`).
- **Границы посчитаны только для KV-3.** Для KV-1 … KV-7 надо добавить точки в `compute_boundary`.
- **Масса и детали — картридж без кожуха пакета.** Число деталей — правило подсчёта, не спецификация.
- **Каталог данных** (`node tools/build_catalog.mjs`) надо пересобрать после коммита, в чистой копии HEAD.
