# Узел FEA: прочность и ресурс ротора в CalculiX

Часть расчётной платформы трека «Простая литая ГТУ-заменитель» (`routes/gtu`).
Осесимметричная модель диска или колеса по табличному профилю: вращение, поле
температур, масса лопаток. На выходе — эквивалентные и средние окружные напряжения,
запас по разрушающей частоте вращения, ресурс по длительной прочности (Ларсон — Миллер).

## Файлы

| Файл | Что это |
|---|---|
| `disk.py` | драйвер: профиль → сетка CAX8 → `.inp` → `ccx` → разбор `.dat`/`.frd` → критерии |
| `materials.json` | Ti-6Al-4V и литой IN-713C: свойства от температуры, источник и статус каждого значения |
| `test_disk.py` | 12 проверок против аналитики и на внутреннюю согласованность |
| `disk_results.json` | результаты примеров (колёса схемы 130 и пакета Taurus 60) |
| `disk_examples.png` | профили примеров и напряжения по средней плоскости |
| `runs/` | входы и выходы ccx (не в git, пересоздаются) |

## Установка (проверено 2026-11-14, Ubuntu 24.04.5, 4 ядра)

```bash
apt-get install -y calculix-ccx        # calculix-ccx 2.21-1, «This is Version 2.21»
pip install numpy scipy                # проверено с numpy 2.5.3, scipy 1.18.1
pip install matplotlib pytest          # необязательно: рисунок (3.11.2) и pytest (9.2.0)
```

время шли другие установки; повтор с `-o DPkg::Lock::Timeout=300` прошёл.

## Формат расчёта (`case.json`)

```json
{"name": "wheel", "material": "ti64", "rpm": 22205,
 "profile": {"r": [0.02, 0.10, 0.2174], "t": [0.11, 0.065, 0.012], "hb": [0, 0.075, 0.0234]},
 "profile_interp": "pchip", "blade_fill": 0.06,
 "T_C": {"r": [0.02, 0.2174], "T": [40, 190]}, "T_ref_C": 20,
 "rim": {"mass_kg": 2.0, "r_cg": 0.23}, "mesh": {"nr": 120, "nz": 16}, "burst_k": 1.0}
```

| Поле | Смысл |
|---|---|
| `profile.r`, `profile.t` | радиус и осевая толщина диска, м; первый радиус 0 — диск без отверстия |
| `profile.zc` | положение средней линии по оси, м (необязательно, по умолчанию 0) |
| `profile.hb` | осевая протяжённость лопаток над диском, м (необязательно) |
| `profile_csv` | вместо `profile`: CSV с колонками `r,t[,zc,hb]` |
| `profile_interp` | `linear` — изломы в точках таблицы; `pchip` — гладкий монотонный сплайн |
| `blade_fill` | доля объёма над диском, занятая лопатками; их масса добавляется в плотность столбца: ρ·(1 + φ·∫hb·r dr / ∫t·r dr) |
| `rim` | нагрузка на ободе от лопаток за ободом: `p_MPa` или `mass_kg` + `r_cg` |
| `T_C` | число или таблица T(r), °C; по оси температура постоянна |
| `material` | ключ из `materials.json` или словарь того же вида |
| `burst_k` | коэффициент использования материала в критерии разрушения (1 — верхняя оценка) |

## Модель

- Элементы CAX8 (CalculiX разворачивает их в C3D20 на секторе 2°). Ось вращения — ось
  y модели, x — радиус. Узлы на оси закреплены по радиусу, один узел средней плоскости — по оси.
- Сетка структурированная: по радиусу ровно `nr` элементов (не меньше одного на участок
  таблицы, остальные — пропорционально длине участка), внутри участка шаг равномерный;
  по толщине `nz` (чётное). Сгущения у отверстия нет — см. «Ограничения».
- Нагрузки: `*DLOAD … CENTRIF` с ω², `*TEMPERATURE` по узлам, растягивающее давление `P2`
  на ободе. Материал — `*ELASTIC` и `*EXPANSION, ZERO=T_ref` таблицами от температуры.
- Лопатки окружной нагрузки не несут: учтена только их масса.
- Выход: Мизес в узлах (`.frd`, экстраполяция) и в точках интегрирования (`.dat`);
  средние окружные σθ,ср = ∫σθ dA / A по меридиональному сечению — двумя способами
  (точки интегрирования и узловое поле).
- **Ворота качества.** Равновесие полудиска: ∫σθ dA = ω²∫ρ r² dA + p·r_o·t_o. Невязка и
  расхождение двух способов, отнесённые к ∫|σθ| dA (но не меньше 0,1 МПа · A — иначе при
  свободном нагреве без напряжений сравнивался бы шум с шумом), должны быть меньше 1·10⁻³ и
  5·10⁻³; иначе расчёт повторяется, а при повторном отказе получает флаг «не доверять».
  Причина: однажды многопоточный ccx 2.21 (решатель SPOOLES в 4 потока) молча выдал
  решение с невязкой 1,6 %, без сообщений об ошибке. В 90 с лишним повторных прогонах
  того же входа это не повторилось. Поэтому ccx запускается в один поток, а параллельно
  идут разные расчёты (4 процесса). Журнала того прогона нет. При проверке 2026-11-14
  24 прогона примеров в 4 потока (журнал ccx: «Using up to 4 cpu(s) for spooles») дали
  те же числа, что и в один поток, невязка не больше 4,5·10⁻⁷ — случай 1,6 % не воспроизведён.
- **Запас по разрушающей частоте вращения** (критерий средних окружных напряжений):
  n_разр / n = sqrt(k · ∫σв(T) dA / ∫σθ dA). Предел прочности берётся при местной
  температуре и осредняется по сечению. При k = 1 оценка верхняя: настоящий k меньше 1,
  его дают испытания на разгонном стенде. Формула верна, когда σθ,ср растёт как ω²: при
  rpm = 0 запас не определяется (`null` и флаг), нагрузка на ободе, заданная давлением
  `p_MPa`, помечается флагом (в запасе она считается растущей как ω²).
- **Ресурс по длительной прочности** (только если у материала есть блок `lmp`):
  P = T[K]·(20 + lg t[ч]), lg σ — полином 2-й степени от P. Выдаются четыре оценки:
  - `local` — по Мизесу в узле при его температуре;
  - `local_s1` — по наибольшему главному напряжению, только растяжение;
  - `local_ip` — по Мизесу в точках интегрирования;
  - `section_mean` и `section_hot` — по σθ,ср при средней и при наибольшей температуре.

  Перераспределение напряжений ползучестью не учитывается, поэтому местные оценки
  консервативны.

## Материалы и источники

Сайты первоисточников в этой сессии закрыты прокси: nickelinstitute.org, matweb.com,
timet.com, ntrs.nasa.gov, arxiv.org. Значения сняты с выдержек поисковой системы, а не
прочитаны в PDF. Статус каждого значения записан в `materials.json`. Перед проектными

тоже не сверил (те же сайты закрыты, лимит поиска исчерпан); исправлен только пересчёт
плотности IN-713C.

консервативна. Прочность IN-713C между 20 и 870 °C интерполируется линейно. Это тоже

Сходимость, 60×8 → 120×16:
- Мизес max, σθ,ср, запас по разрушению — в пределах 0,3 %;
- местный ресурс — 0,1 % по Мизесу, 1,5 % по главному напряжению, 3,7 % по Мизесу в точках
  интегрирования;
- на сетке 240×32 срок по главному напряжению — 10 010 ч, по Мизесу — 5 690 ч (прогон
  проверяющего 2026-11-14, в `disk_results.json` не входит).

Чувствительность к неточному КТР сплава: при α×1,15 Мизес у оси растёт на 3 %, ресурс
по Мизесу падает до 990 ч, по главному напряжению — до 8 200 ч, запас по разрушению не
меняется.

Что из этого следует (в пределах условных профилей):
- Титановое колесо схемы 130 при 506 м/с проходит с запасом. Отверстие под стяжку
  40 мм допустимо: 0,72 от минимального σ0,2.
- При 618 м/с (колесо Taurus 60, на принятом пределе 620 м/с) отверстие 57 мм даёт
  местную текучесть у отверстия (1,08 σ0,2). Без отверстия — 0,60 σ0,2 и запас 1,59.
  Предел 620 м/с для титана реален только при ступице без сквозного отверстия. Пластика
  в модели не учтена.
- Литое колесо турбины по запасу на разрыв проходит (1,43). Ресурс по длительной
  прочности у горячего обода — около 5,7–9,8 тыс. ч: это 0,65–1,1 года непрерывной
  работы. Ресурс упирается в температуру обода и полотна. Чтобы решать, нужны настоящий
  профиль, поле температур из теплового расчёта (OpenFOAM) и данные длительной
  прочности литого сечения. Варианты, которые стоит проверить: охлаждение задней
  стороны колеса, понижение TIT, другой литой сплав.

## Ограничения

- Расчёт линейно-упругий: пластичность, ползучесть с перераспределением и малоцикловая
  усталость (пуски-остановы) не считаются.
- Лопатки учтены только массой: напряжений в самих лопатках, у их корней и от изгиба
  нет. Для этого нужна трёхмерная секторная модель (C3D10 на геометрии Gmsh).
- Поле температур задаётся по радиусу и по оси не меняется.
- Сгущения сетки нет: шаг по радиусу равномерный внутри участка таблицы. Малое отверстие
  не разрешается: при отверстии 0,2 мм в диске 400 мм и `nr` = 200 σθ у отверстия 211 МПа
  против аналитических 282 (−25 %). Для своего колеса — сходимость на двух сетках, как в примерах.
- Ползучесть титана не оценивается: блока `lmp` для Ti-6Al-4V нет.
