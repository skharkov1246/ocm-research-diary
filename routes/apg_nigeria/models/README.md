# Расчётные модели фаз 1–3 (попутный газ, Нигерия)

Скрипты и их выводы, которые агенты-оценщики и агенты-скептики писали во время
проверки 14 вариантов скида (фаза 2) и сборки решений (фаза 3). Каталог назван
по варианту и роли: `power/` — оценщик, `power_skeptic/` и `power_y2/` —
скептики (второй год эксплуатации), и так далее.

| Каталог | Что внутри |
|---|---|
| `deal/` | Модель сделки «энергия якорному покупателю»: `dealcore.py`, `deal2.py`, `deal3.py`, `multi_model.py`, воронка факелов `funnel.py` |
| `judge_run/` | Перепроверка порогов тарифа судьёй (`judge_check.py`) |
| `wb/nigeria_flares.csv` | Факелы Нигерии 2012–2025 по спутниковым данным VIIRS |
| `msa_dl/` | Выгрузки UN Comtrade (торговая статистика) |
| остальные | модели и проверки по вариантам: `lpg`, `cng`, `minilng`, `compute`, `nacn_ng`, `msa_*`, `meoh`, `urea_ng`, `pyro`, `pao_*`, `gtl`, `multi`, `carbon*` |

## Происхождение данных и лицензии

- `wb/nigeria_flares.csv` — World Bank, Global Gas Flaring Reduction Partnership,
  оценки объёмов сжигания по данным VIIRS. Лицензия World Bank Open Data — CC BY 4.0.
- `msa_dl/*.json` — UN Comtrade, фактические данные торговой статистики.
- Тексты сторонних документов (законы, отчёты, статьи), которые агенты извлекали
  для чтения, в репозиторий не перенесены. Ссылки на них — в `../nigeria_facts.txt`.

## Известные ограничения

- В `deal/multi_model.py` константа `MW_PER_MMSCFD = 4.64` смешивает высшую теплоту
  сгорания с КПД по низшей; корректно ≈4.40. Исправление — в раунде 2.
- Код модели майнинга «v2» (числа $159 и $65 за PH/сутки) утерян до переноса;
  воспроизводимый `compute/mining10.py` даёт $239 и $103–113.
- Скрипты писались под пути временной папки сессии; пути к входным файлам при
  повторном запуске нужно поправить на относительные.
