======================================================================================

  булит D=3.0 м x L=9.0 м = 70.7 м3 -> нужно 1.66 -> 2 шт
  t_обечайки = 2.0*1500/(138.0*1.0-0.6*2.0) + 3.0 = 24.9 мм -> 25 мм
  t_днища   = 24.8 мм -> 25 мм
  масса обечайки = pi*3.0*9.0*0.0249*7850.0 = 16.60 т
  масса 2 днищ  = 2*1.084*pi*D^2/4*t*rho = 2.98 т
  БУЛИТ = 19.6 т; два булита = 39.2 т стали под давлением

  при 5,200 $/т (ASME U-stamp FOB Китай, ДОПУЩЕНИЕ):

2. ДОБАВЛЯЕМОЕ: УЗЕЛ ГИДРОЛИЗА МОЧЕВИНЫ (сосуд 48 бар изб.)
======================================================================================
  NH3 в горелку 9.377 кмоль/ч; CO(NH2)2 + H2O -> 2NH3 + CO2
  мочевина 4.689 кмоль/ч = 281.6 кг/ч = 2253 т/год
  CO2 попутно 206.3 кг/ч — БАЛЛАСТ, идёт в горелку вместе с NH3
  гидролизёр D0.5 x 3.2 м, расч. 48 бар изб., 316L: t=11.7 мм, масса 0.51 т
  -> новая граница давления 48 бар изб. с ~30 кг NH3 внутри (узел nacn_urea)
     это ЦЕНА безопасности хранения, а не бесплатный обед: 1 сосуд вместо 2 булитов,
     инвентарь 0.05% от прежнего, но регистрация/ПК/ЭПБ нужны те же.

  БАЛЛАСТ В ГОРЕЛКЕ (то, чего не было при безводном NH3):
    CO2 4.689 кмоль/ч на 71.210 кмоль/ч смеси = +6.6% объёма
    -> сечение всего горячего тракта +6.6%, и это до пара
    -> подогрев воздуха до 480 C (предел по самовоспламенению CH4 537 C) обязателен,
       иначе сетка теряет 94-168 K (расчёт в calc/nacn_urea) -> селективность падает

3. ПОЧЕМУ БУФЕР 1 СУТКИ И ОДНА ЛИНИЯ РЕАКТОРА НЕСОВМЕСТИМЫ
======================================================================================
  CH4+NH3+1.5O2 -> HCN+3H2O : dH = -469.5 кДж/моль  [из Hf, CRC]
  CH4+2O2 -> CO2+2H2O       : dH = -802.3 кДж/моль
  баланс по O2: подано 10.799, на HCN ушло 1.5*6.377=9.565, остаток 1.234 кмоль/ч
  -> дожигается CH4 0.617 кмоль/ч
  ТЕПЛОВЫДЕЛЕНИЕ = 832 (HCN) + 138 (дожиг) = 969 кВт
  вынос теплa газом 78.3 кмоль/ч x 40.1 Дж/моль/К x (1373-673) = 611 кВт
  ПОТЕРИ ЧЕРЕЗ ФУТЕРОВКУ (замыкание баланса) = 969 - 611 = 358 кВт
  (сюда же входят эндотермический крекинг CH4 и разложение непрореагировавшего NH3)

  ТУРНДАУН. Тепловыделение ~ x (нагрузка), потери ~ const (задаются dT через стенку):
    x*Q_rel = x*Q_sens*(T-T_in)/(T_set-T_in) + Q_loss
    (T-T_in) = (T_set-T_in)*(Q_rel/Q_sens - Q_loss/(x*Q_sens))

   нагрузка  T сетки, C  dT от номинала  вердикт
       100%        1100              +0  норма
        90%        1054             -46  норма
        80%         997            -103  СЕЛЕКТИВНОСТЬ ПАДАЕТ, проскок NH3
        70%         924            -176  СЕЛЕКТИВНОСТЬ ПАДАЕТ, проскок NH3
        60%         826            -274  СРЫВ
        50%         689            -411  СРЫВ

  ВЫВОД: одна линия физически не умеет 50% — сетка теряет ~-411 K.
  При буфере 7 суток спрос рудника сглаживался баком. При буфере 1 сутки —
  не сглаживается ничем: линия либо 100%, либо СТОП с холодным пуском.
    буфер 7 сут = 151 м3 ; буфер 1 сут = 21.6 м3
    при недельном разбросе спроса +-30% (ДОПУЩЕНИЕ, нужен профиль рудника):
      7-суточный бак покрывает 175 т при недельном дефиците 14.4 т -> покрывает
      1-суточный бак покрывает 25 т -> НЕ покрывает, нужен останов

  ХОЛОДНЫЕ ПУСКИ В ГОД (каждый — проход через область воспламенения,
  а запас до ВПВ всего 0.6-1.4 п.п., внутри погрешности метода):
    1 линия + буфер 1 сут : ~31 пусков/год
    2 линии x 50%         : ~4 пусков/год (только смена сетки), нагрузка
                            меняется включением/отключением линии, рабочая точка не плывёт
    -> сокращение проходов через опасную область в 8 раз

  ЭТО И ЕСТЬ ОБОСНОВАНИЕ РАЗДЕЛЕНИЯ РЕАКТОРА. Не резервирование, не надёжность —
  а то, что урезанный товарный парк перекладывает регулирование с бака на реактор,
  а реактор регулироваться не умеет.

4. СВЕЧА 30 м vs 15 м: ТЯГА НЕ ГЛАВНОЕ, ГЛАВНОЕ — РАЗБАВЛЕНИЕ
======================================================================================
  ro(воздух, 30 C) = P*M/RT = 1.1604 кг/м3
  газ за скруббером насыщен при 60 C: y_H2O=0.197, M=26.72 -> ro=0.9778 кг/м3
  тяга H=15 м: dP = g*H*(ro_a-ro_s) = 9.81*15*0.1826 = 26.9 Па
  тяга H=30 м: dP = g*H*(ro_a-ro_s) = 9.81*30*0.1826 = 53.7 Па
  потери на насадке аварийного абсорбера ~5.3 Па (узел safety_econ)
  -> запас 5.2x уже при 15 м. ПО ТЯГЕ 30 м НЕ НУЖНЫ. Обоснование другое:

  МАКСИМАЛЬНАЯ ПРИЗЕМНАЯ КОНЦЕНТРАЦИЯ (гауссов факел, классика):
    C_max = 2*Q/(pi*e*u*H^2)  при sigma_z = H/sqrt(2)
    сценарий: полный байпас аварийного скруббера, Q = 172.3 кг/ч = 0.0479 кг/с
    u = 2.0 м/с (штиль, класс устойчивости F — худший случай)
    H, м  C_max, мг/м3  C_max, ppm  порог
      15         24.91       22.54  >AEGL-3 (15 ppm) — ЛЕТАЛЬНАЯ ЗОНА
      30          6.23        5.63  <AEGL-2 (7.1 ppm)
      45          2.77        2.50  <AEGL-2 (7.1 ppm)
  AEGL-2/AEGL-3 60 мин для HCN 7.1 / 15 ppm — ПО ПАМЯТИ (US EPA AEGL), НЕ СВЕРЕНО.
  Расчёт скрининговый: ровная местность, без подъёма факела. Тарква — не ровная.
  Для проекта нужен PHAST/ALOHA. Но знак однозначен: 15 м не проходит, 30 м проходит.

5. ЗАМКНУТЫЙ ВОДООБОРОТ В ГАНЕ: ИСПАРИТЕЛЬНЫЙ ПРУД НЕ РАБОТАЕТ
======================================================================================
  осадки Тарква ~1900 мм/год [ПО ПАМЯТИ, нужна станция GMet]
  испарение с водоёма = 0.7 * испаряемость 1450 = 1015 мм/год
  НЕТТО = 1900 - 1015 = +885 мм/год
  пруд 2500 м2 НАБИРАЕТ +2213 м3/год вместо того чтобы испарять
  -> 'испарительный пруд' — решение из Невады/Австралии. В юго-западной Гане это
     ИСТОЧНИК воды, а не сток. Замкнутый контур невозможен без выпарки,
     а выпарку узел safety_econ отверг (горячий цианидный аппарат).
  ЕДИНСТВЕННОЕ РАБОЧЕЕ РЕШЕНИЕ: обезвреживание INCO + доочистка до норм EPA Ghana
     + РАЗРЕШЁННЫЙ сброс. Это меняет состав оборудования и цену — см. capex.py.

  ЛИВНЕВОЙ РАСЧЁТ ОБВАЛОВАНИЯ (то, что база наверняка не учла):
    площадь в обваловании 900 м2, ливень 180 мм/24ч (1/25 лет, ДОПУЩЕНИЕ)
    объём ливня = 162 м3
    + 110% наибольшего бака (25 м3) = 27.5 м3
    ТРЕБУЕМАЯ ЁМКОСТЬ ОБВАЛОВАНИЯ = 190 м3
    средний загрязнённый сток = 1710 м3/год = 195 л/ч
    -> узел обезвреживания должен быть рассчитан на ЛИВЕНЬ, а не на технологический сток.
