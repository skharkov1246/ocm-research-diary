# AWS job — Fe-zeolite α-O, FAITHFUL real-CHA run (CASSCF + NEVPT2)

**Что это.** Окончательный тест α-O на **реальной геометрии каркаса**: спиновые
состояния Fe(IV)=O в кластере, вырезанном из **настоящей IZA-структуры CHA**
(6-кольцо, 2 Al в пара-позициях, силанольные кэпы), с активным сайтом,
отрелаксированным xTB. Известный ответ — **S=2** (Snyder, Nature 2016,
`10.1038/nature19059`). Запуск — на инстансе с AWS (в веб-сессии AWS нет).

**Почему AWS.** На 4 vCPU только DF-SCF занял ~1 ч (465 базисных функций), а
CASSCF+NEVPT2 по трём спинам (CAS(16e,11o)=22 кубита) за часы не досчитался; плюс
эфемерный контейнер убивает длинные джобы. На нормальном инстансе это часы, не дни.

## Запуск (под ключ)
```bash
# на EC2-инстансе, из корня репозитория:
chmod +x calc/aws_run.sh
./calc/aws_run.sh
```
- **Всё нужное закоммичено и pyscf-only.** Кластер уже построен из реального
  каркаса CHA и отрелаксирован (`calc/alpha_o_cha_relaxed.xyz`) — на инстансе НЕ
  нужны ase/zse/tblite, только `pyscf` (ставится скриптом).
- **Инстанс:** ≥16 vCPU, ≥64 ГБ RAM (`c7i.8xlarge` / `r7i.4xlarge`).
- **Dead-man switch:** инстанс **сам терминируется** при выходе (успех/ошибка/
  таймаут `TIMEOUT`, по умолч. 12 ч). Нужна IAM-роль с `ec2:TerminateInstances`
  (иначе фоллбэк — `shutdown -h now`).
- **Заберите результаты ДО терминации:**
  `aws s3 cp calc/fe_zeolite_cha_results.json s3://YOUR_BUCKET/`

## Что вернётся
`calc/fe_zeolite_cha_results.json` — энергии трёх спинов на уровнях CASSCF и
NEVPT2, плюс `verdict_e_cas` / `verdict_e_nevpt2` с `matches_known_S2`. Пришлёшь
JSON — впишу исход в карточку Fe-zeolite (зелёный **только** если реально S=2).

## Честные оговорки
- Кластерная модель (не периодика), базис def2-SVP, Al-сайтинг = para,
  геометрия активного сайта от xTB. Валидируем **порядок** спинов на реальной
  геометрии каркаса, не абсолютный зазор (для него — периодика/бол. базис).
- Геометрия каркаса — из IZA CHA (реальные кристаллографические координаты).

## Контекст (уже сделано, в `main`/ветке)
- Constructed-кластеры (считаются локально): S=2 устойчиво на v1, v2-extended,
  v2-minimal-**relaxed** — CASSCF **и** NEVPT2. См. `fe_zeolite_alpha_o_nevpt2*`.
- Реальный кластер: `build_alpha_o_cha.py` (сборка из IZA) → `relax_cha_xtb.py`
  (xTB-релакс) → `alpha_o_cha_relaxed.xyz` → **этот джоб** (`fe_zeolite_cha_sp.py`).
- FeO⁺ анкор (`feo_cation.py`): контур воспроизвёл известный ⁶Σ⁺. ✓
