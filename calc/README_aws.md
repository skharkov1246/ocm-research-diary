# AWS job — Fe-zeolite α-O cluster validation (Track B)

**Что это.** Готовый к запуску прогон, который проверяет, воспроизводит ли наш
контур известный ответ для α-O: **высокоспиновое S=2 Fe(IV)=O** основное
состояние (Snyder, Nature 2016, `10.1038/nature19059`). Запускается **не из
сессии сайта** (там нет AWS), а на инстансе с расчётным стеком.

**Почему AWS, а не локально.** Спиновую энергетику кластера (CASSCF/CASCI) можно
посчитать и локально, но честный α-O — это встроенный кластер с бо́льшим активным
пространством (Fe 3d + oxo O 2p + каркасные O 2p) и **полным VQE-statevector**,
а это уже тяжело (тот же барьер симулятора, что у FeMoco/24q в дневнике).

## Запуск
```bash
# на EC2-инстансе, из корня репозитория:
chmod +x calc/aws_run.sh
./calc/aws_run.sh                 # идеализированная модель (прогон всего пути)
./calc/aws_run.sh site.xyz 0      # РЕАЛЬНАЯ структура кластера + суммарный заряд
```
- Рекомендуемый инстанс: compute-optimized, ≥32 ГБ RAM (`c7i.4xlarge` /
  `r7i.2xlarge`).
- **Dead-man switch** встроен: инстанс **сам терминируется** при выходе (успех,
  ошибка или таймаут `TIMEOUT`, по умолчанию 6 ч) — утечки инстансов нет. Нужна
  IAM-роль с `ec2:TerminateInstances` (иначе фоллбэк — `shutdown -h now`).
- Результаты: `calc/fe_zeolite_alpha_o_results.json` + лог
  `calc/fe_zeolite_alpha_o.log`. Заберите их с инстанса ДО терминации
  (например `aws s3 cp`), затем числа можно вписать в карточку Fe-zeolite.

## Честные оговорки (важно)
- **Геометрия.** По умолчанию используется *идеализированная* минимальная модель
  `[Fe(O)(OH)₂]` (нейтральная, Fe(IV), низко-координированная, слабое поле O) —
  это **стенд-ин, не кристаллографический α-O**. Для верного результата подайте
  реальную структуру через `--xyz` (фрагмент Fe-обменного цеолита CHA/MOR/FER,
  H-терминированный; при желании — с точечными зарядами Madelung, как у [NiO₆] в
  катодах). Вердикт ровно настолько хорош, насколько хороша геометрия.
- **Метод.** CASSCF без динамической корреляции: валидируем **порядок** спиновых
  состояний (основное ли S=2?) и мультиреференс, **не** количественный зазор
  (для него — CASPT2/NEVPT2 + больший базис).
- Зелёная плашка «валидировано» ставится на сайте **только** если прогон реально
  даёт S=2 как основное. Если нет — это честный null (как у голого ядра, шаг 1),
  и статус остаётся «цель валидации». Числа не подгоняются.
