# Отливки двигателя-заменителя: сплав, класс, контроль, запрос, приёмка

В двигателе один ротор: два центробежных колеса компрессора (Ti-6Al-4V или алюминий) и одно литое колесо турбины из
никелевого сплава. Корпуса и камера сгорания тоже литые. Отливки делаются в КНР, сборка и испытания — в России. Навык
описывает, как перевести расчёт в требования к отливке, собрать пакет запроса и принять отливку. **Отправка запросов и
выбор завода — в КВАНТ** (навык `supplier-rfq` в kvant-sourcing-dashboard), здесь их нет. Пометки: **[Р]** — файл
репозитория, открыт; **[В]** — по выдержке поиска, документ не открыт (номер, название, редакция — предварительно, до
сверки с реестром); «вывод» — наше заключение из фактов; «не проверено» — источника нет. Ни один внешний документ из
сессии не открылся (раздел «Источники»). На 14.11.2026 требований к отливкам в репозитории нет.

## 3. Деталь → сплав → процесс

| деталь | что принято в модели [Р] | сплав и процесс | что известно |
|---|---|---|---|
| колесо компрессора, титан | фрезерованное, U ≤ 620 м/с (`LIM["U_ti"]`), D ≤ 0,90 м (поковка) | базовый путь — поковка Ti-6Al-4V и фрезеровка; вариант — литьё по выплавляемым моделям ZTC4 + ГИП | литые тела вращения Ti-6Al-4V до Ø600 мм, без ГИП нет пластичности [В]; Ø1,5–2 м — заявления производств о конструкционных отливках, не о колёсах [В]; литое колесо Ø0,9 м **не подтверждено**; литьё + ГИП — самый дешёвый путь к ответственной детали, прочность немного ниже деформированного металла [В]; тонкие сечения трудны из-за реакции металла с формой [В] |
| колесо компрессора, алюминий | фрезерованное, U ≤ 520 м/с, T за колесом ≤ 200 °C | базовый путь — фрезерованное; вариант — литое ZL114A (≈ A357) | свойств ZL114A при литье по выплавляемым моделям нет; T6 после литья под низким давлением — σв ≈ 355, σ0,2 ≈ 303 МПа [В] |
| колесо турбины, монотор | радиальное колесо 0,50 м «да», до 0,70 «на пределе»; монотор 0,45/0,60 м, U ≤ 480 м/с; газ ≤ 950 °C без охлаждения | литьё по выплавляемым моделям в вакууме, равноосное, мелкое зерно в ступице; K418 или K418B (≈ IN713C / IN713LC) | цельнолитые колёса малых двигателей — IN713LC, IN718, MAR-M247 [В]; в ступице, где напряжения наибольшие, зерно крупное — против этого процессы FGP, Grainex, Microcast-X [В]; главная беда литых колёс K418 — горячие трещины, K424 склоннее к ним [В]; один завод КНР заявляет Ø500 мм и 50 кг [В]; вариант — кольцо лопаток K418B на порошковом диске, диффузионная сварка в ГИП (тезисы 2017) [В] |
| горячие корпуса, диффузоры | — | мелкозернистое литьё K4169 — цельные корпуса, кожухи, диффузоры ниже 700 °C [В]; жаростойкие стальные отливки GB/T 8492-2014 [В] | задние корпуса турбины отливают целиком вместо «частями и сварка» [В] |
| холодные корпуса | — | алюминиевые отливки GB/T 9438-2013; стальные отливки под давлением GB/T 16253-2019 (MOD ISO 4991:2015) [В] | JB/T на отливки корпусов **газовых** турбин не найден; ближайший — JB/T 10087-2016, паровые турбины [В] |
| камера сгорания | — | **не проверено**: сплава жаровой трубы в исследованиях нет | температура стенки — навык `openfoam-combustor` |

Точка № 3 считается при газе перед турбиной 1000 °C, а предел литого равноосного колеса без охлаждения в `LIM` — 950 °C
(`T_rad_max`) [Р]: температура металла обода берётся из теплового расчёта, а не по газу. Направленная кристаллизация (DZ)
и монокристалл (DD) нужны только для осевой ступени (README: неохлаждаемая монокристальная лопатка — до 1 050 °C [Р]). Это
отдельная дорогая цепочка с керамическими стержнями; национального стандарта КНР на стержни нет, групповой — с 06.2023 [В].

## 4. Марки КНР и западные аналоги

**Ни одной пары «марка КНР = AMS/ASTM/UNS» официальный документ не подтверждает**: все пары — от продавцов, агрегаторов
или по совпадению состава. Писать «близкий аналог по составу, эквивалентность не установлена»; в запросе требовать
сертификат с фактическим составом и свойствами против обеих спецификаций.

| K418B | то же | IN713LC | не найдена | продавец [В]; меньше C и Ti, выше пластичность и ударная вязкость |
| K438 | — | IN738LC | — | продавец [В]; лопатки ~900 °C, стоек к горячей коррозии |
| K417G | — | IN100 (с него воспроизведён) | — | BUAA [В]; междендритная пористость, ГИП её уменьшает |

| ZL114A | GB/T 1173-2013; отливки — GB/T 9438-2013 | A357.0 | AMS 4219F (A357.0-T6), AMS 4241C (D357.0-T6) | продавец и Total Materia [В]; другой продавец сопоставляет ZL114 с A356 |

## 5. Класс отливки и объём контроля

AMS 2175 (бывший MIL-STD-2175) [В, вторичная копия]: класс задаёт объём контроля, группа (Grade A–D) — критерии приёмки.
Class 1 — единичное разрушение угрожает жизни персонала или ведёт к потере аппарата; Class 2 — существенный
эксплуатационный ущерб; Class 3 и 4 — остальные, с запасом прочности ≤ 200 % и > 200 %. Без указания — Grade C (у Class 4 —
D); все зоны Class 1 не хуже C, высоконагруженные — не хуже B. Редакция A — 2003, пересмотр 2010, подтверждение 2018; по
карточке перепродавца её заменил B:2024 — сверить у SAE. Аналога «класс + группа» в КНР и России не найдено.

| деталь | класс и группа (вывод, не норма) | объём (памятка литейного производства [В], сверить с AMS 2175) |
|---|---|---|
| колёса, монотор | Class 1; ступица и корни лопаток — Grade B или выше, остальное — не ниже C | 100 % визуальный, капиллярный и рентген; ступица — ещё КТ и зерно на макрошлифе (вывод) |
| корпуса, камера сгорания | решает конструктор по последствиям разрушения | Class 2 — 100 % визуальный и капиллярный (магнитопорошковый), рентген выборочно по таблице I; Class 4 — капиллярный выборочно, рентген — если задан |

| метод | западный ряд [В] | ряд КНР [В] | заметки [В] |
|---|---|---|---|
| рентген | ASTM E1742/E1742M-23, E1030/E1030M-21 (отливки); индикаторы E1025-18, E747 | GB/T 5677-2018 (сталь, медь, Ni, Al, Ti; раздел «订货须知»); цифровой — GB/T 39638-2020; классы дефектов: Al — GB/T 11346-2018, Ti — GB/T 46654-2025 | трещину видно, только если луч идёт вдоль неё (E1030); эталонные снимки E192 — стальные отливки до 25,4 мм, никель не назван; Al — E155/E2422 |
| капиллярный | ASTM E1417/E1417M-21e1; материалы — AMS 2644 (Type I люминесцентные, уровни ½–4) | HB/Z 61-1998 (авиация); GB/T 9443-2019 — только стальные и чугунные отливки | в России — ГОСТ 18442-80 |
| КТ | ASTM E1814-25 (отливки), E1570-19 | GB/T 29070-2012, GB/T 29069-2012 | артефакты принимают за дефекты, они искажают размеры |
| зерно, макро- и микроструктура | ASTM E112-25, E340-23 | GB/T 14999.1-2025 (макро), 14999.2-2025 (микро); зерно, шаг дендритов, микропористость отливок — GB/T 14999.7-2010 (место в редакции 2025 не определено) | в России — ГОСТ 5639-82 |

Методические стандарты критериев приёмки не задают (E1742-00, E1814) — критерии пишутся в чертеже и ТУ. Открытого
числового критерия зерна ступицы нет: его задаёт чертёж заказчика, число **не проверено**.

## 6. Чертёж и техтребования

1. Марка со стандартом и годом (аналог — справочно, «эквивалентность не установлена»); литьё по выплавляемым моделям
   (熔模铸造 / 精铸) в вакууме, равноосное; у колёс — мелкое зерно в ступице: способ — завода, результат — по разделу 5.
2. Состояние: литое, после ГИП (热等静压) или термообработки. Стандарта КНР на ГИП никелевых отливок не найдено; ГИП титановых
   изделий — GB/T 45339-2025 (статус у источников разный), стальных отливок — ASTM A1080/A1080M-24 (режим — по соглашению
   сторон), Ti — AMS 4985E, 4991G [В]. Режимы из статей — ориентир, не норма: K417G — 1180 и 1240 °C, 160 МПа, 4 ч; ZTC4 —
   915 °C [В]. Термообработка — по ТУ на сплав (HB/Z 140-2004, AMS 2773 — по названию) [В].
3. Класс и группа по зонам (зоны — эскизом), методы, объём и критерии по разделу 5, уровень чувствительности капиллярного.
4. Свойства (раздел 9): какие, при каких температурах, на каких образцах. Отдельно отлитые образцы той же плавки — умолчание
   спецификации SAE (копия AMS 5410B [В]); вырезанные из детали первой партии — место и размер по согласованию, нормы для
   них отдельно: в отчёте NASA у вырезанных ниже длительная прочность [В].
5. Допуски — ISO 8062-3:2023 (DCTG, GCTG) или GB/T 6414-2017 (классы CT, запись «прочие размеры — CT9 по GB/T 6414») [В].
   ISO 8062-3 не применяется к 3D-модели без указанных размеров: ответственные размеры — на 2D. Значений DCTG и CT для литья
   по моделям не найдено. Фланцы и посадки — с припуском. В России — ГОСТ Р 53464-2009 [В].
6. Ремонтная заварка — по зонам (авиационные отливки — AMS 2694 [В]); в зонах Grade B колеса — решение конструктора.
   Маркировка — номер плавки (炉号) и номер детали (AMS 2804D [В]).
7. Балансировка — ISO 21940-11:2016 (Amd 1:2022 — таблица сведений для чертежа ротора) или GB/T 9239.1-2006 (= ISO 1940-1:2003)
   [В]. G 2.5 — роторы газовых турбин, Uper [г·мм] = 9549·G [мм/с]·m [кг]/n [об/мин]; колёса по API 617 — G0.67 (вторичные).

## 7. Пакет запроса (RFQ) и письмо

Литейное производство КНР для цены просит 2D с допусками и/или 3D, марку, свойства, термообработку, требования к качеству
и поверхности [В]; 3D (STEP/IGES) — той же версии, что 2D; без количества цена ориентировочная [В, вторичный]. Пакет: 3D и
2D одной редакции; ТУ (раздел 6) на английском и китайском **одним файлом** — у карточки КВАНТ один слот вложения
(`supplier-rfq`); базис FCA — ICC советует FCA вместо EXW при пересечении границы, экспорт оформляет продавец [В]; цены без НДС.

Экспортный контроль [В]: уведомление № 21 (2024) МОФКОМ с 01.07.2024 контролирует оборудование, ПО и технологии изготовления
ГТД; по сводке KPMG — и оборудование направленного и монокристального литья, стержни, модели, оболочки (китайская выдача не
подтвердила). Перечень двойного назначения (МОФКОМ № 51) — с 01.12.2024. Под контролем ли готовые равноосные отливки — не установлено.

```text
Subject: RFQ — <part>, investment casting, <alloy> / 询价：<部件>，熔模铸造
Dear Sir or Madam, we request a quotation (报价) for the investment casting (熔模铸造) of <part>: drawing <No., rev.>, 3D model <same rev.>.
1. Material: <CN grade> per GB/T 14992-2025 and <casting standard, year>; close composition analogue <AMS/ASTM spec>, equivalence
   not assumed. Please confirm the grade designation against GB/T 14992-2005.
2. Process: vacuum melting and pouring, equiaxed, fine grain in the hub; HIP (热等静压) <yes/no>; heat treatment per <spec>.
3. Casting class <n> per AMS 2175, zones per drawing. NDT: 100 % radiography (铸件 射线照相检测; GB/T 5677-2018 / ASTM E1742), 100 %
   fluorescent penetrant (渗透检测; ASTM E1417, AMS 2644 level <n>), CT of the hub, grain size (晶粒度). Acceptance: drawing <sheet>.
4. Properties at <temperatures> on separately cast test bars of the same heat (单铸试棒) and specimens machined from the first
   casting (本体取样): tensile (GB/T 228.2-2015 / ASTM E21), stress-rupture (持久; GB/T 2039-2024 / ASTM E139).
5. Documents: EN 10204 3.1 per heat (炉号) and lot (GB/T 18253-2018), 3.2 if a buyer's inspector is named; first article
   inspection (首件鉴定) per AS9102 or equivalent; dimensional report.
6. Quantity: <n> prototypes, estimated series <n> pcs/year. Delivery FCA <place>; prices excluding VAT.
7. Please state: largest casting of this alloy you have made (diameter, mass, NDT report); master alloy source and standard; HIP
   in-house or subcontracted; lab accreditation (CNAS / ISO/IEC 17025); NDT personnel certification (ISO 9712 / GB/T 9445-2024);
   Nadcap if any; whether a PRC export licence is required.
Best regards, <sender — filled in KVANT>
```

Термины без опоры на название стандарта — рабочий перевод, сверить с заводом: 单铸试棒, 随炉试棒 (образцы, залитые с
плавкой), 本体取样 / 本体解剖, 炉号, 询价, 报价. Остальные термины письма взяты из названий стандартов КНР [В].

## 8. Приёмка

1. **Сертификат** EN 10204:2004 тип 3.1 на плавку и партию — подтверждает представитель изготовителя, независимый от
   производства; 3.2 — ещё и представитель заказчика или назначенный инспектор, назначенный до испытаний: 3.1 нельзя
   «повысить» до 3.2 (вторичный). EN 10204 задаёт тип документа, а не испытания: PMI, УЗК, третья сторона — отдельно
   [В, вторичный]. В КНР — GB/T 18253-2018 (= ISO 10474:2013) [В]. Номер плавки = маркировка = упаковочный лист.
2. **Образцы** — по п. 6.5: растяжение при нагреве — ASTM E21 / GB/T 228.2-2015; длительная прочность — ASTM E139-24 /
   GB/T 2039-2024 (MOD ISO 204:2023, включает 持久) / HB 5150 (литые Ni, по статье) / ГОСТ 10145-81 [В]. Режимы для K418
   и IN713C — из ТУ на сплав (AMS 5391 или HB), а не из статей.
3. **Входной НК** в России — тем же методом и по тем же критериям, что у завода; персонал — ISO 9712, EN 4179 или NAS 410 [В].
4. **Первое изделие**: AS9102 Rev C (06.2023) — Form 1 обозначение, Form 2 материалы и спецпроцессы, Form 3 характеристики
   (вторичные); в КНР — GJB 908-1990 «首件鉴定» [В]. Первую отливку модели — вскрыть для зерна и свойств (вывод).
5. **Разгон колёс.** Открытой нормы для промышленной ГТУ нет: процент в API 616 не найден (форум: уставка защиты 105 % MCS,
   не проверено), стандарта КНР на 超速试验 тоже. Ориентиры: API 617 — каждое колесо компрессора 115 % MCOS 1 мин
   (отраслевой журнал); 14 CFR 33.27 — 5 мин в двигателе при 120 %, на коротких режимах OEI — 115 % [В]. Число в запросе —
   требование КВАНТ по решению владельца, не «по стандарту». Колесо первой партии, разогнанное до разрушения, даёт k для
   запаса по разрушающей частоте (`calculix-rotor`, шаг 5) — вывод.

## 9. Связь с расчётом прочности (`calculix-rotor`) и интерфейсами (`gtu-dropin`)

`disk.py` берёт из `materials.json` `density`, `nu`, `E_GPa(T)`, `alpha_mean_1e6(T)`, `uts_MPa(T)`, `ys_MPa(T)` и `lmp`
(P = T[K]·(20 + lg t[ч])) [Р] — их и просить у завода.

| деталь | что нужно | при каких температурах | что есть сейчас [Р] |
|---|---|---|---|
| колесо турбины | ρ, E, ν, α, σв, σ0,2; длительная прочность (σ, T, часы до разрушения, 100–1000 ч и дольше); константы малоцикловой усталости, если есть | от 20 °C до наибольшей температуры металла по тепловому расчёту; пока его нет — точки файла 20; 815,6; 870; 926,7; 982,2 °C | `in713c`: σв при 20 и 870 °C, σ0,2 только при 20 °C, ν без источника, Ларсон — Миллер по 5 точкам отдельно отлитых образцов |
| колесо компрессора, Ti | ρ, E, ν, α, σв, σ0,2; малоцикловая усталость | 20, 300, 427 °C (сетка `ti64`) | `ti64` — деформируемый; литого ZTC4 после ГИП нет |
| колесо компрессора, Al | E, α, σв, σ0,2 | 20 … 200 °C | нет |
| горячие корпуса | σв, σ0,2, длительная прочность | по тепловому расчёту | нет |

- По `fea/README.md` ресурс литого колеса турбины у горячего обода — 5,7–9,8 тыс. ч; он упирается в температуру и данные
  длительной прочности **литого сечения** [Р]: главный запрос — длительная прочность образцов, вырезанных из колеса.
  Констант усталости в `materials.json` нет — без них `calculix-rotor` ресурс в циклах не выдаёт.
- Новое число — в `materials.json` со статусом: метод, образцы, источник «сертификат завода, вне репозитория», без имени завода.
- `gtu-dropin`: масса и центр масс отливок — пункты «опоры и рама», «подъём и выкатка» (не тяжелее, проходит в проём);
  фланцы входного и выхлопного корпусов — «вход», «выхлоп»: размеры — из вердикта, на отливке — припуск под обработку.

## 11. Обязательные правила

- Пара марок — «близкий аналог», никогда «=». Стандарт с пометкой [В] — «предварительно», не в заголовок.
- Открытый репозиторий: заводов поимённо, контактов, цен, условий и ответов на запрос нет; можно типы производств и
  публично известные отраслевые организации без контактов. Запросы отсюда не отправляются, завод выбирают в КВАНТ.
- Тексты AMS, ASTM, ISO, API платные и не читались: ссылаться по номеру и области, требований по памяти не цитировать.
- Литое титановое колесо Ø0,9 м не подтверждено, базовый путь — поковка. Нет источника — «не проверено».

## 12. Типовые ошибки

- K418 записан как «= IN713C», марка — без года стандарта (после GB/T 14992-2025 обозначение могло измениться); предел
  0,9 м из `D2_MAX` прочитан как предел литого титанового колеса; свойства отдельно отлитых образцов перенесены на ступицу.
- Методический стандарт (E1742, E1814, GB/T 5677) указан вместо критериев приёмки; снимки E192 приложены к никелевой
  отливке толще 25,4 мм; GB/T 9443-2019 назначен никелевой отливке.
- Отправлена только 3D-модель (ISO 8062-3 к модели без размеров не применяется); 3.1 «повышают» до 3.2 после испытаний;
  EXW вместо FCA; разгон «по API 616» без числа в источнике.

## 13. Проверка результата

```bash
python3 -I - routes/gtu/casting/gtu_casting_*.json <<'EOF'
import json, re, sys
NEED = {"part", "checked", "alloy", "process", "class", "ndt", "properties_needed", "rfq"}
BAD = re.compile(r"[\w.+-]+@[\w-]+\.\w+|\+\d[\d ()-]{8,}\d|\b(?:USD|CNY|RMB|EUR)\b|руб\.|долл\.|юан", re.I)
bad = 0
for f in sys.argv[1:]:
    t = open(f, encoding="utf-8").read(); d = json.loads(t); miss = NEED - d.keys()
    errs = [f"нет полей {sorted(miss)}"] * bool(miss) + [f"похоже на контакт или цену: {m!r}" for m in BAD.findall(t)]
    if "эквивалентность не установлена" not in d.get("alloy", {}).get("analog_status", ""): errs.append("аналог без оговорки")
    if "не норма" not in d.get("class", {}).get("status", ""): errs.append("класс AMS 2175 без пометки «вывод, не норма»")
    bad += len(errs); [print("ОШИБКА", f, e) for e in errs]
print("итог: ошибок", bad); sys.exit(1 if bad else 0)
EOF
```

`node tools/build_catalog.mjs --check` (после коммита), `node tools/smoke.mjs`; дифф — глазами: нет заводов, цен, контактов, локальных путей.
